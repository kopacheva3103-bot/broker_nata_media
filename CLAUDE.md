# broker_nata_media

Монтаж вертикальных Reels для брокера Натальи Копачевой — движок в `montage/`
(Python + ffmpeg, см. `montage/README.md`).

## Стандарт монтажа — обязателен
Каждый новый ролик оформляется по `montage/STANDARD.md`: в `project.yaml`
первой строкой `preset: premium` (Montserrat, белый + золото #E6B450, титры по центру).
Не менять оформление и формулировки без согласования с Натальей.
Если шрифт не найден — сообщить до рендера, не подменять системным.

## Материалы
- Брать только те материалы, на которые указала Наталья (ссылки на Яндекс/Google Диск).
- Не использовать содержимое `photos/` в роликах.
- Готовые ролики отдавать в чат (≤30 МБ) и страницей скачивания (она с Mac).
