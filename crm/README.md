# CRM брокера: контакты → категории → адресные рассылки

Одна программа (`crm.py`, работает на вашем компьютере) делает четыре вещи:

1. **Загружает телефонную книгу** из файла `.vcf` (iPhone, Android) или `.csv` (Google Контакты).
2. **Делит людей на категории (теги)**: `покупатель`, `инвестор`, `продавец`, `аренда`, `москва`, `vip`…
3. **Рассылает адресные предложения** с вашего номера по категориям: Telegram → WhatsApp → SMS.
   Каждому человеку уходит **одно** сообщение: через первый канал, который сработал.
4. **Хранит базу**: карточку контакта, заметки, согласие, «СТОП», историю отправок по каждой кампании.

База лежит в `crm/data/crm.db` только на вашем компьютере. В git она не попадает
(этот репозиторий публичный, поэтому `.gitignore` не пропускает туда контакты, `.csv`, `.vcf` и ключи).

## 1. Установка (один раз)

```bash
cd crm
pip install -r requirements.txt
cp config.example.ini config.ini   # заполните по комментариям внутри
```

## 2. Выгрузить контакты из телефона

- **iPhone**: icloud.com → Контакты → выделить все (⌘A) → ⚙️ → «Экспорт vCard».
- **Android**: Контакты → ⋮ → «Импорт/экспорт» → «Экспорт в .vcf».
- **Google Контакты**: contacts.google.com → «Экспортировать» → vCard или Google CSV.

```bash
python crm.py import contacts.vcf
python crm.py tags            # какие категории уже есть (группы из телефона тоже подтянутся)
```

## 3. Разметить категории и согласие в Excel

```bash
python crm.py export база.csv
```

Откройте `база.csv` в Excel и заполните:
- `tags`: категории через запятую, например `покупатель, москва, до 30 млн`;
- `consent`: поставьте `1` тем, кто согласился получать предложения (см. раздел «Закон»);
- `stopped`: `1` означает «не писать никогда»;
- `telegram`: юзернейм, если знаете (иначе Telegram ищется по номеру).

Сохраните файл и загрузите его обратно: `python crm.py import база.csv`.

Для одного человека то же самое делается командой:
```bash
python crm.py set +79161234567 --add-tags инвестор --consent 1 --note "звонил, ищет коммерцию"
python crm.py history +79161234567      # карточка и все отправки этому человеку
python crm.py list --tag инвестор
```

## 4. Рассылка

Текст пишется в файле, например `templates/example_offer.txt`. Подстановки:
`{hello}` (Доброе утро / Добрый день / Добрый вечер), `{first_name}`, `{name}`.

```bash
# 1) пробный прогон: покажет, кому уйдёт и как будет выглядеть текст, ничего не отправит
python crm.py send --name "Долина Премьер" --template templates/example_offer.txt \
    --tags инвестор,vip --exclude-tags продавец --channels tg,wa \
    --photo https://raw.githubusercontent.com/kopacheva3103-bot/broker_nata_media/main/photos/1789710083_dolina-premier-220mln.jpg

# 2) то же самое с --send — реальная отправка
python crm.py send ... --send
```

- Кампания запоминает, кому уже отправлено. При повторном запуске эти люди **не получат** сообщение второй раз, поэтому большую базу можно рассылать частями по дням.
- Между сообщениями делается случайная пауза 20–60 секунд, за один запуск уходит не больше 40 сообщений на канал (настраивается в `config.ini` и через `--limit`).
- Кто без согласия или со «СТОП», тот пропускается автоматически.

```bash
python crm.py campaigns                              # все рассылки и статистика
python crm.py report "Долина Премьер" --file отчёт.csv
python crm.py sync-stop                              # кто ответил «стоп» в Telegram → больше не писать
```

## Каналы: как это работает с вашим номером

| Канал | Как отправляется | Что нужно |
|---|---|---|
| **tg** Telegram | Автоматически от вашего личного аккаунта (библиотека Telethon). Человек ищется по юзернейму или по номеру телефона. | `api_id`/`api_hash` с my.telegram.org. При первом запуске Telegram пришлёт код, его нужно ввести. Если у человека нет Telegram, программа переходит к следующему каналу. |
| **wa** WhatsApp | Полуавтоматически: создаётся страница `data/wa_links_….html` со ссылками, текст в них уже вставлен. На телефоне нажимаете имя, потом «Отправить». | Ничего. |
| **sms** SMS | Автоматически с SIM-карты вашего Android-телефона через бесплатное приложение **SMS Gateway for Android** (sms-gate.app). | Установить приложение, включить Local server и вписать адрес, логин и пароль в `config.ini`. Отправка идёт по тарифу вашего оператора. |

**Почему WhatsApp не полностью автоматический.** WhatsApp банит личные номера за
неофициальных ботов (whatsapp-web.js, Baileys и т.п.), и номер можно потерять
навсегда. Официальная автоматизация возможна только через WhatsApp Business API:
на отдельный бизнес-номер, с платными шаблонами, одобренными Meta. Ссылки wa.me
безопасны, и сообщения уходят с вашего номера.

**Чтобы Telegram не ограничил аккаунт:** пишите только тем, кто вас знает
(контакты из вашей книги), не больше 30–50 сообщений в день новым людям,
текст с обращением по имени. Если Telegram ответит `PeerFlood` или `FloodWait`,
программа сама остановит канал; тогда сделайте паузу на сутки.

## Закон (РФ): коротко

- **38-ФЗ «О рекламе», ст. 18**: рекламу по телефону, SMS и в мессенджеры можно
  отправлять только с **предварительного согласия** получателя. Отмечайте это
  согласие в колонке `consent`. Без него программа не отправит.
- В каждом сообщении нужен способ отказаться («ответьте СТОП»). Отказавшимся
  ставится `stopped=1`, вручную или через `sync-stop`.
- **152-ФЗ**: база контактов содержит персональные данные. Храните её только у себя,
  не выкладывайте `data/` и выгрузки `.csv` в интернет и в публичный репозиторий.
