# Монтаж-коллаж (пилот, ролик «ЖК Время 1 — детсад», 06.11.2026)

Формат по образцу Reels с «фигурой-стикером»: на каждую фразу своя сцена —
спикер вырезан с белым контуром, видео объекта в фото-карточках, плашки со словами
из озвучки, счётчики, чек-листы. Фон утверждён: размытое видео объекта (вариант 4).

Порядок (Python 3.13: faster-whisper, rembg, opencv-python-headless):

1. `python3.13 prep.py raw.mp4 work/` — вырезает паузы и дубли (правила движка), ×1,1 → `talk.mp4`, `words.json`.
2. `python3.13 matte.py work/talk.mp4 work/matte.mp4` — маска спикера (u2net_human_seg, 432×768).
3. фон: склейка роликов объекта, ×0,5, `gblur=sigma=16` → `work/bgloop.mp4`.
4. `python3.13 collage.py work/ src/ out.mp4` — рендер; `PREVIEW="1.0,6.5"` — только кадры-превью.
5. звук: голос + музыка Mixkit (−10 дБ), постоянный уровень до −14 LUFS.

`clean.py` убирает из маски светлое кресло за спикером (низкая насыщенность, жёлто-зелёный
оттенок, крупные пятна у края фигуры); кожа, волосы и блики на ткани не трогаются.

Сцены и плашки пока описаны в `collage.py` под этот ролик; следующий шаг — вынести их в YAML-проект.

## Шаблон для новых роликов (с 06.11.2026)
Сцены задаются файлом проекта `reels/<ролик>.py` (FIX — правки субтитров, HIDE_IDX — где прятать
субтитры, HOOK/HOOK_BIG/HOOK_CUT — хук, `scenes()` — сцены по индексам слов из `words.json`):
`REEL=reels/reel2.py python3.13 collage.py work2 src out.mp4`.
Типы сцен: hook, talk (спикер на фоне помещения, без кресла), sticker, card, cards, paper (doc/plan),
checklist, facts. Ролик 1 описан в самом `collage.py` (сцены по умолчанию).
