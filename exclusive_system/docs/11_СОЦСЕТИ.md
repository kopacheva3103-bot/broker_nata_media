# Подключение Instagram и Threads (≈30 минут, один раз)

Что даёт: по ссылкам на публикации в 04_КОНТЕНТ система сама подтягивает
- **Instagram** (рилс, посты, карусели): просмотры, охват, сохранения;
- **Threads**: просмотры;
- **Telegram** (публичный канал): просмотры — без настройки;
- **YouTube / Shorts**: просмотры — после подключения сервиса «YouTube Data API v3» в редакторе Apps Script (Сервисы ＋).

Статистика отдаётся только по **своим** аккаунтам (которые вы подключили). Заявки SMM вносит вручную.

## Что нужно заранее

- Instagram — **профессиональный аккаунт** (Бизнес или Автор): Instagram → Настройки → Тип аккаунта.
- Аккаунт на **developers.facebook.com** (вход через Facebook, бесплатно).

## Instagram

1. developers.facebook.com → **Мои приложения → Создать приложение** → сценарий использования (use case) про **Instagram API** («Управлять сообщениями и контентом в Instagram»).
2. В приложении: **Сценарии использования → Instagram API → Настроить → «API setup with Instagram business login»**.
3. Шаг «Generate access tokens» → **Add account** → войдите в Instagram агентства и разрешите доступ (Instagram попросит роль тестировщика — примите приглашение в Instagram: Настройки → Приложения и сайты / Website permissions).
4. Нажмите **Generate token** напротив аккаунта → скопируйте ключ (начинается с `IG…`). Ключ живёт 60 дней, система будет продлевать его сама.
5. Нужные разрешения: `instagram_business_basic`, `instagram_business_manage_insights`.

## Threads

1. В том же или новом приложении добавьте сценарий **Threads API** («Access the Threads API»), разрешения `threads_basic` и `threads_manage_insights`.
2. **Роли приложения → Роли → Добавить людей → Threads Tester** → ваш аккаунт Threads.
3. В Threads: **Настройки аккаунта → Разрешения для сайтов (Website permissions) → Приглашения** → принять.
4. В настройках сценария Threads — **User Token Generator → Generate access token** → скопируйте ключ (начинается с `TH…`).

## Ввести ключи в систему

Таблица → **Сервис → Подключить Instagram / Threads** → вставьте ключи → **Проверить и сохранить**. Должно появиться «подключён @имя_аккаунта». Ключи хранятся в свойствах скрипта, в таблице их не видно (доступны только редакторам проекта Apps Script — не давайте доступ к таблице посторонним).

Затем **Меню → Обновить статистику соцсетей**, а чтобы обновлялось само каждое утро — **Сервис → Включить ежедневное обновление**.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| «ключ не подошёл» | Сгенерируйте ключ заново; проверьте, что аккаунт профессиональный и разрешения добавлены |
| «Не найдены в аккаунте: N ссылок» | Публикация из другого аккаунта или старше ~500 последних публикаций |
| Охват / сохранения пустые у Instagram | Для этого типа публикации Instagram их не отдаёт (например, сторис) |
| Перестало обновляться через 2 месяца | Ключ истёк (не обновлялся 60 дней) — введите новый |
| Threads-ключ перестал работать через час | Сгенерирован короткий ключ — сообщите мне, добавлю обмен на долгий |
