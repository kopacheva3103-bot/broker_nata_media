## Вкладка объекта «▸ Название (ID)»

Создаётся сама, когда в 01_ОБЪЕКТЫ заполнены ID и название. Разделы 1–7 заполняет команда, 8–10 собираются из журналов. Строки внутри табличного раздела можно вставлять — при обновлении системы они сохраняются.

### ДОКУМЕНТЫ ОБЪЕКТА — из папки на Google Диске

Кладите файлы в папку объекта (Word, PDF, презентации, таблицы, фото) — список и ссылки появляются сами: каждое утро или меню «Обновить документы объектов». Вставлять ссылки вручную не нужно.

Только чтение. Столбцы: Документ (ссылка); Раздел папки; Тип; Обновлён.

### 1. АНАЛИТИКА: АНАЛОГИ

Аналоги вносим вручную (ЦИАН, Авито, BestPlace). Цена за м² считается сама. Минимум 3 аналога.

Строк по умолчанию: 8. Столбцы: Аналог (адрес, ЖК) (текст); Назначение / тип (текст); Площадь, м² (число); Цена, ₽ (сумма); Цена за м² (**формула**); Источник / ссылка (ссылка); Комментарий (текст).

### 2. ЦЕНА И ПОЗИЦИОНИРОВАНИЕ

Сравнение с аналогами считается само. Вывод по цене можно вставить из разбора Claude.

- Медиана цены за м² по аналогам — **формула**
- Наша цена за м² (из 01_ОБЪЕКТЫ) — **формула**
- Отклонение от медианы — **формула**
- Рекомендуемая цена, ₽ — сумма
- Минимальная цена для торга, ₽ — сумма
- Позиционирование (1–2 предложения) — текст
- Вывод по цене — текст
- Полный анализ (ссылка) — ссылка

### 3. СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ

Под какой бизнес можно продать / сдать. Для каждого: чек-лист из 06_БИБЛИОТЕКА, что запросить у УК и собственника, кого привлечь (консультанты, подрядчики, их КП), вывод.

Строк по умолчанию: 6. Столбцы: Сценарий (текст); Чек-лист (список: чек-листы 06); Что проверить / документы от УК (текст); Консультанты, подрядчики, КП (текст); Вывод (текст); Статус (список: 07 Статус сценария); Ссылки (ссылка).

### 4. ЦЕЛЕВЫЕ АУДИТОРИИ

Кому предлагаем. Пишите аудиторию так же, как в 03_ОБЗВОН_И_КП, — тогда цифры справа посчитаются сами. Неочевидные идеи (посольства, аэропорт…) — тоже сюда.

Строк по умолчанию: 8. Столбцы: Аудитория (текст); Кто (список: 07 Кто); Портрет: зачем им объект (текст); Где искать (текст); Приоритет (список: 07 Приоритет); В базе (**формула**); КП отправлено (**формула**); Интересно (**формула**).

### 5. КП И МАТЕРИАЛЫ

КП клиенту — с контактами агентства; КП партнёру — без контактов (для пересылки). Файлы — в папке объекта «КП и презентации».

Строк по умолчанию: 6. Столбцы: Материал (текст); Какое (список: 07 Какое КП); Для аудитории / сценария (текст); Ссылка (ссылка); Готовность (список: 07 Статус работы); Комментарий (текст).

### 6. КАНАЛЫ И ПАРТНЁРЫ

Где и через кого продвигаем: площадки, соцсети, брокеры, УК, консультанты, ассоциации, рассылки.

Строк по умолчанию: 8. Столбцы: Канал / партнёр (текст); Что делаем (текст); Ответственный (список: 07 Сотрудник); Статус (список: 07 Статус работы); Результат (текст); Ссылка (ссылка).

### 7. ВЫВОДЫ И РЕШЕНИЯ ПО СТРАТЕГИИ

Что поняли и что меняем (в т.ч. итоги оперативок по объекту). Старые записи не удаляйте — это история стратегии.

Строк по умолчанию: 6. Столбцы: Дата (дата); Вывод / решение (текст); Кто (список: 07 Сотрудник); Что делаем дальше (текст).

### 8. ПЛАН-ФАКТ: ТЕКУЩАЯ НЕДЕЛЯ И НЕЗАКРЫТЫЕ ЗАДАЧИ

Собирается из 02_ЗАДАЧИ. Задачи добавляются там (или меню «Создать план недели»).

Только чтение. Столбцы: Неделя; Задача; Исполнитель; План; Факт; %; Срок; Статус.

### 9. РАБОТА С БАЗОЙ И КОНТЕНТ

Из 03_ОБЗВОН_И_КП и 04_КОНТЕНТ. Подробности — в журналах (фильтр по ID объекта).

Только чтение. Столбцы: Период; Компаний в базе; Звонков; КП; Ответов; Интересно; Передано в CRM; Публикаций.

### 10. КОНТЕНТ ОБ ОБЪЕКТЕ

Из 04_КОНТЕНТ: последние публикации и то, что в работе. Цифры вносит SMM.

Только чтение. Столбцы: Дата; Площадка; Формат; Тема; Статус; Просмотры; Охват; Ссылка.

«Стратегия заполнена» (H3 во вкладке, столбец в 01): Заполнено из 6: ≥3 аналога; рекомендуемая цена; ≥1 сценарий; ≥3 аудитории; ≥1 КП со ссылкой; ≥2 канала.
