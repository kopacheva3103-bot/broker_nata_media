# A–C. Архитектура системы (v2)

## Главная идея

```
CRM (TopenLab)            = клиенты, показы, сделки, переписка. Система их НЕ дублирует.
Система маркетинга (Sheets) = стратегия продажи по каждому эксклюзиву + работа команды:
                             аналитика и цена → сценарии использования → аудитории → КП → каналы → решения
                             + план-факт по неделям, обзвон и КП ассистента, контент SMM
Отчёт клиенту (Doc + PDF)   = собирается сам из план-факта в формате «Приложение №1 к Договору»
```

Каждый факт вводится **один раз** и в **одном месте**; остальное — формулы и скрипт. Лишних столбцов нет: всё, что можно посчитать, считается само.

| Что происходит | Куда вводится | Что считается само |
|---|---|---|
| Взяли эксклюзив | 01_ОБЪЕКТЫ: ID из CRM + название (и реквизиты для отчёта) | проверка ID, цена за м², **вкладка объекта создаётся сама** |
| Разрабатываем стратегию | вкладка «▸ Объект (ID)», разделы 1–7 | цена за м² аналогов, медиана и отклонение, цифры по аудиториям, % заполнения стратегии |
| План недели | меню «Создать план недели» + свои задачи в 02_ЗАДАЧИ | факт по звонкам / КП / ответам / публикациям, % выполнения, просрочки, перенос |
| Ассистент звонит и отправляет КП | 03_ОБЗВОН_И_КП (1 строка = 1 компания) | недели, факт задач, цифры в отчёте и во вкладке |
| SMM публикует | 04_КОНТЕНТ (1 строка = 1 публикация) | факт задач, охваты на дэшборде и в отчёте |
| Понедельник | 05_ОТЧЁТ_КЛИЕНТУ: объект + неделя → «Создать отчёт клиенту» | Google Doc, PDF, архив, № отчёта |

## Вкладка объекта

1. **Аналитика: аналоги** (ЦИАН / Авито / BestPlace вручную, цена за м² считается).
2. **Цена и позиционирование**: медиана аналогов, наша цена за м², отклонение; рекомендуемая и минимальная цена, вывод (можно вставить разбор Claude).
3. **Сценарии использования**: сценарий → чек-лист из библиотеки → что проверить и какие документы запросить у УК → консультанты и КП подрядчиков → вывод → статус.
4. **Целевые аудитории**: кто, портрет, где искать, приоритет; справа сами считаются «в базе / КП отправлено / интересно» из 03.
5. **КП и материалы**: КП клиенту (с контактами) и партнёру (без контактов), презентации под аудитории, ссылки.
6. **Каналы и партнёры**.
7. **Выводы и решения** — история стратегии.
8. **План-факт** текущей недели и незакрытые задачи (из 02).
9. **Работа с базой и контент** — цифры за неделю и всего (из 03 и 04).
10. **Контент об объекте** (из 04).

## Google Диск

```
СИСТЕМА ЭКСКЛЮЗИВОВ/
  00_ТАБЛИЦА/      — сама таблица
  01_ОБЪЕКТЫ/      — папка на объект «Название (ID)»: Аналитика, КП и презентации, Отчёты, Фото и видео
  02_ШАБЛОНЫ/      — шаблон еженедельного отчёта (вёрстку можно менять)
```
Если у объекта уже есть своя папка (как «ЖК Время»), вставьте её ссылку в 01_ОБЪЕКТЫ → «Папка объекта» — отчёты лягут в неё.

## Связи

- **Claude** — через подписки: «Промпт для Claude по объекту» собирает промпт с данными вкладки; «Внести задачи с оперативки» принимает таблицу задач из ответа Claude.
- **Google Календарь** — задачи со сроком событиями, исполнителям приглашения.
- **Соцсети** — просмотры Telegram и YouTube по ссылкам из 04_КОНТЕНТ.

## Доступ и история

Таблицу открывают руководитель, ассистент и SMM под своими корпоративными email (впишите их в 07_СПРАВОЧНИКИ → «Сотрудник / Email» и перезапустите установку — доступ выдастся сам). Пароли не передаются. Все правки с автором и старым значением — в 09_ИСТОРИЯ. Клиент доступа не получает — только PDF.
