# I. Установка и обновление (≈15 минут)

## Первая установка

1. Google Drive → **Создать → Google Таблицы** (или откройте уже созданную «СИСТЕМА…»).
2. **Расширения → Apps Script** → удалите всё в «Код.gs» → вставьте содержимое **`dist/Code.gs`** (весь код одним файлом) → 💾.
3. ⚙ Настройки проекта → «Показывать файл манифеста appsscript.json» → замените его содержимым `dist/appsscript.json` → 💾.
4. Вернитесь в таблицу, обновите страницу (F5) → меню **МАРКЕТИНГ ОБЪЕКТОВ → Сервис → ⚙ Установить / обновить систему** → разрешите доступ («Дополнительные настройки» → «Перейти в проект» → «Разрешить» — это ваш собственный скрипт).
5. Через 1–3 минуты: 11 листов, папки `СИСТЕМА ЭКСКЛЮЗИВОВ / 00_ТАБЛИЦА, 01_ОБЪЕКТЫ, 02_ШАБЛОНЫ` на Диске, шаблон отчёта, триггер, стартовая библиотека (8 чек-листов, 7 промптов, регламенты).

## Настроить под команду

- **07_СПРАВОЧНИКИ → Сотрудник / Роль / Email**: реальные имена и корпоративные email ассистента и SMM. Перезапустите установку — им откроется доступ к таблице и папке (каждый работает под своим аккаунтом, пароли не передаются, авторы правок видны в 09_ИСТОРИЯ). При первом использовании меню Google попросит разрешение и у них.
- **08_НАСТРОЙКИ**: шапка отчёта (реквизиты через « | »), исполнитель, подпись, порог «дней без работы», задачи недели по умолчанию (справа).

## Проверка

**Сервис → Загрузить пример (ЖК Время · Лермонтовская 1)** → **Сервис → Запустить самопроверку** → лист 99_САМОПРОВЕРКА весь зелёный. Затем 05_ОТЧЁТ_КЛИЕНТУ → пример + неделя 2026-W38 → «Создать отчёт клиенту» — отчёт в вашем формате.

## Обновление на новую версию

Замените код в Apps Script на новый `dist/Code.gs` → **Установить / обновить систему** → **Сервис → Обновить все вкладки объектов**. Данные журналов, вкладок, настроек и справочников сохраняются; формулы, списки, оформление пересоздаются.

Не переставляйте и не переименовывайте столбцы журналов — установщик остановится и скажет, какой столбец не на месте. Свои столбцы — только справа.

> Для технических: `clasp push` из папки `apps_script/` (файлы по одному вместо `dist/Code.gs`).
