# I. Установка (≈15 минут)

## 1. Создать таблицу и вставить скрипт

1. Откройте Google Drive → **Создать → Google Таблицы** (пустая таблица). Название можно не менять — скрипт переименует в «СИСТЕМА УПРАВЛЕНИЯ ЭКСКЛЮЗИВАМИ».
2. В таблице: **Расширения → Apps Script**.
3. В редакторе Apps Script:
   - Слева «Файлы» → удалите содержимое `Код.gs` и вставьте туда содержимое `00_Config.gs`, переименуйте файл в `00_Config`.
   - Для каждого следующего файла из папки `apps_script/` нажмите **＋ → Скрипт**, назовите его как в репозитории (без `.gs`) и вставьте содержимое: `01_Schema`, `02_Formulas`, `03_Setup`, `04_Triggers`, `05_Reports`, `06_Strategy`, `07_Planning`, `08_Control`, `09_Dialogs`, `10_TestData`, `11_SelfTest`, `12_Utils`, `13_Menu`.
   - **＋ → HTML** → имя `AddActionDialog` → вставьте `AddActionDialog.html`.
   - ⚙ **Настройки проекта** → включите «Показывать файл манифеста appsscript.json» → откройте `appsscript.json` в редакторе и замените содержимым из репозитория (часовой пояс Москва, V8, нужные разрешения).
4. Нажмите 💾 **Сохранить**.

> Альтернатива для технических пользователей: `npm i -g @google/clasp`, `clasp login`, `clasp create --type sheets --title "СИСТЕМА УПРАВЛЕНИЯ ЭКСКЛЮЗИВАМИ" --rootDir apps_script`, `clasp push`.

## 2. Первый запуск

1. В редакторе выберите функцию `setupSystem` → **Выполнить**. Google попросит разрешения (таблицы, документы, Drive, отправка почты для ежедневной сводки) → «Дополнительные настройки» → «Перейти в проект» → «Разрешить». Это ваш собственный скрипт, данные никуда не уходят.
   - Из редактора установка идёт без диалогов (итог — в «Журнале выполнения»). Можно и иначе: обновите таблицу (F5) и запустите **УПРАВЛЕНИЕ ЭКСКЛЮЗИВАМИ → Сервис → ⚙ Установить / обновить систему**.
2. Установка занимает 1–3 минуты. В итоге:
   - 13 листов с формулами, списками, форматированием и защитой формул;
   - в Drive папка **СИСТЕМА ЭКСКЛЮЗИВОВ** с `00_MASTER` (туда перенесена таблица), `01_STRATEGIES`, `02_WEEKLY_REPORTS`, `03_TEMPLATES` (шаблоны отчёта и стратегии);
   - установлен триггер «при изменении» (ID, история, автоматика).
3. Обновите страницу таблицы — появится меню **УПРАВЛЕНИЕ ЭКСКЛЮЗИВАМИ**.

## 3. Проверка на тестовых данных (рекомендуется)

1. **Меню → Сервис → Загрузить тестовые данные** — появятся Остров, Аносино Парк, Павловы Озёра.
2. **Меню → Сервис → Запустить самопроверку** → «Да» (проверить создание отчёта и PDF).
3. Откроется лист 99_САМОПРОВЕРКА: все строки должны быть зелёными ✓.
4. Посмотрите 09_ДЭШБОРД, 11_КОНТРОЛЬ, 07_ОТЧЕТ и созданный PDF в `02_WEEKLY_REPORTS/Остров (OBJ-001)`.

**Перед началом реальной работы** удобнее всего сделать **новую чистую таблицу** по шагам 1–2 (или удалить тестовые строки из 01, 02, 03, 04, 06, 12, 13 и лист 99_САМОПРОВЕРКА). Самопроверка рассчитана на таблицу, где есть только тестовые данные.

## 4. Настройки

Лист **10_НАСТРОЙКИ** (жёлтые ячейки):
- пороги: дни без активности (7 — красный, 4 — жёлтый), нет новых лидов (14), пересмотр стратегии (30), окончание эксклюзива (14), падение конверсии (30%), доля отказов (50%) и минимальные выборки;
- день отчёта клиенту (5 = пятница) и периодичность (7 дней);
- подпись отчёта: агентство, ваше имя, контакт;
- email ассистента (при повторной установке ему откроется доступ к папке и таблице);
- email для ежедневной сводки → затем **Сервис → Включить ежедневную сводку на email**;
- справа — **KPI по умолчанию** для «Создать план недели» (например, Контакты 30, Лиды 2, Показы 1 на объект).

Лист **08_СПРАВОЧНИКИ**: впишите реальных ответственных (столбец «Ответственный», роль, email — по email форма «Добавить действие» подставит автора). Любые списки можно дополнять. Столбцы «Класс» не меняйте — это системный смысл значения.

## 5. Доступ

- Ассистент: **Настройки доступа → Редактор** (или email в 10_НАСТРОЙКИ + повторная установка). Первый запуск меню у ассистента тоже попросит разрешения — это нормально.
- Клиент: доступа к таблице и папкам **не получает**. Ему отправляется только PDF.
- Формулы защищены «мягко»: при попытке изменить Google предупредит. Это защита от случайной порчи, а не от вас.

## 6. Обновление системы

Когда появится новая версия кода: замените файлы в Apps Script → **Сервис → ⚙ Установить / обновить систему**. Данные журналов, настройки и справочники сохраняются; формулы, списки и расчётные листы пересоздаются.

**Не переставляйте и не переименовывайте столбцы журналов** — установщик остановится с сообщением, какой столбец не на месте. Добавлять свои столбцы можно только справа от последнего столбца журнала (после блоков 04/06 — ещё правее).
