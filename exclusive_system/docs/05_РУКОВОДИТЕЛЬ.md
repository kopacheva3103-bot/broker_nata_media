# Инструкция для руководителя

## Понедельник (30–40 минут)

1. **Оперативка** (Zoom). После встречи: **Меню → Промпт для Claude по объекту → «Оперативка → задачи»** → скопировать → вставить в Claude (ваша подписка) вместе с расшифровкой Zoom → Claude вернёт таблицу задач → **Меню → Внести задачи с оперативки** → вставить → «Проверить» → «Внести задачи». Задачи попадут в 02_ЗАДАЧИ (источник «Оперативка»), решения — в раздел 7 вкладок объектов. Таблицу можно набрать и вручную: `ID объекта | Блок | Задача | Исполнитель | Единица | План | Срок | Решение`.
2. **Меню → Создать план недели** → неделя → «Перенести незакрытые задачи?». Каждому объекту в работе встанут задачи по умолчанию (08_НАСТРОЙКИ: обзвон 10, КП 8, публикации 2 — меняются там же). Незакрытые задачи прошлой недели переносятся, исходные строки остаются со статусом «Перенесено».
3. В **02_ЗАДАЧИ** допишите задачи по стратегии (найти проектировщиков, запросить документы у УК, подготовить презентацию под аудиторию) — исполнитель, единица и план. Формулируйте так, чтобы можно было показать клиенту.
4. **Отчёты клиентам за прошлую неделю:** 05_ОТЧЁТ_КЛИЕНТУ → объект → неделя → проверьте предпросмотр → при желании комментарий → **Создать отчёт клиенту**. Проверьте Google Doc; правили текст — **Обновить PDF отчёта**. PDF отправляете клиенту сами.
5. **Меню → Синхронизировать задачи с календарём** — задачи со сроком появятся в вашем Google Календаре, исполнители получат приглашения на свой email (из 07_СПРАВОЧНИКИ). Чтобы это происходило само каждое утро — **Сервис → Включить ежедневное обновление** (заодно обновляется статистика соцсетей). Подключение Instagram и Threads — `11_СОЦСЕТИ.md`.

## Ежедневно (5 минут)

**00_ДЭШБОРД**: красные строки — объект дольше порога без работы; «% плана» жёлтый — отставание; «Просрочено» — у кого. Блок «По сотрудникам» показывает, кто не выполняет план. Меню **Проверить просрочки** — список по исполнителям.

## Стратегия объекта

Документы (Word, PDF, аналитика, КП, презентации) просто кладите в папку объекта на Google Диске — в верхнем разделе вкладки «Документы объекта» они появятся сами со ссылками. Объекты не в работе (продан, сдан, пауза) скрываются из вкладок автоматически.

Вкладка «▸ Объект (ID)» — рабочее место по стратегии. «Стратегия заполнена» (вверху справа и в 01): ≥3 аналога, рекомендуемая цена, ≥1 сценарий, ≥3 аудитории, КП со ссылкой, ≥2 канала. Для разбора цены, сценариев, аудиторий и КП: встаньте во вкладку объекта → **Меню → Промпт для Claude по объекту** → выберите промпт → «Скопировать» → вставьте в Claude (своя подписка, без доплат). Система сама добавит к промпту данные объекта: реестр, аналоги, цену, сценарии, аудитории, КП, каналы, решения. Ответ перенесите в нужный раздел вкладки. Кнопка «Спросить Claude» прямо в таблице (с API-ключом) — отложена.

## Что где менять

- Сотрудники, email, списки — 07_СПРАВОЧНИКИ (столбцы «Класс» не менять).
- Шапка отчёта, подпись, порог дней, задачи недели — 08_НАСТРОЙКИ.
- Вид отчёта — документ «Шаблон еженедельного отчёта» в `02_ШАБЛОНЫ` (метки `{{…}}` не удалять).
