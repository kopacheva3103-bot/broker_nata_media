# Инструкция для руководителя

## Понедельник (30–40 минут)

1. **Оперативка** (Zoom). Решения по объекту записывайте во вкладку объекта → раздел 7 «Выводы и решения».
2. **Меню → Создать план недели** → неделя → «Перенести незакрытые задачи?». Каждому объекту в работе встанут задачи по умолчанию (08_НАСТРОЙКИ: обзвон 10, КП 8, публикации 2 — меняются там же). Незакрытые задачи прошлой недели переносятся, исходные строки остаются со статусом «Перенесено».
3. В **02_ЗАДАЧИ** допишите задачи по стратегии (найти проектировщиков, запросить документы у УК, подготовить презентацию под аудиторию) — исполнитель, единица и план. Формулируйте так, чтобы можно было показать клиенту.
4. **Отчёты клиентам за прошлую неделю:** 05_ОТЧЁТ_КЛИЕНТУ → объект → неделя → проверьте предпросмотр → при желании комментарий → **Создать отчёт клиенту**. Проверьте Google Doc; правили текст — **Обновить PDF отчёта**. PDF отправляете клиенту сами.

## Ежедневно (5 минут)

**00_ДЭШБОРД**: красные строки — объект дольше порога без работы; «% плана» жёлтый — отставание; «Просрочено» — у кого. Блок «По сотрудникам» показывает, кто не выполняет план. Меню **Проверить просрочки** — список по исполнителям.

## Стратегия объекта

Вкладка «▸ Объект (ID)» — рабочее место по стратегии. «Стратегия заполнена» (вверху справа и в 01): ≥3 аналога, рекомендуемая цена, ≥1 сценарий, ≥3 аудитории, КП со ссылкой, ≥2 канала. Для разбора цены, сценариев, аудиторий и КП используйте промпты из 06_БИБЛИОТЕКА (пока — копированием в Claude; кнопка «Спросить Claude» прямо в таблице — следующий этап).

## Что где менять

- Сотрудники, email, списки — 07_СПРАВОЧНИКИ (столбцы «Класс» не менять).
- Шапка отчёта, подпись, порог дней, задачи недели — 08_НАСТРОЙКИ.
- Вид отчёта — документ «Шаблон еженедельного отчёта» в `02_ШАБЛОНЫ` (метки `{{…}}` не удалять).
