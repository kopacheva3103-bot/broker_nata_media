# 09 — Анализ конкурентов: как собирать аналоги и считать рыночную цену

Для ассистента. Результат — файл «Анализ аналогов — <объект> — дд.мм.гггг» в папке объекта «Аналитика» и вывод по цене во вкладке объекта.
Шаблон: 02_ШАБЛОНЫ → «Шаблон — Анализ аналогов (конкуренты)». Жёлтое заполняете вы, серое считается само.

## 1. Когда делаем

- Новый объект — до первого разговора о цене с собственником.
- Раз в месяц по каждому объекту в работе (рынок меняется, конкуренты снижают цену или уходят).
- Когда нет звонков и показов 2 недели подряд — первым делом проверяем цену.

## 2. Подготовка (5 минут)

1. Сделайте копию шаблона в папку объекта «Аналитика» и назовите: `Анализ аналогов — Осоргино — 27.09.2026`.
2. Заполните блок «НАШ ОБЪЕКТ». Обязательно: **сделка, площадь, ремонт, цена собственника**. Остальное — для себя.
3. Площадь берём общую (для ПСН — по ЕГРН; для домов — площадь дома, участок отдельно).

## 3. Где искать

| Площадка | Зачем |
|---|---|
| **ЦИАН** — основная | больше всего объявлений, есть история цены и «снято с публикации» |
| Авито | частники, объекты вне ЦИАН |
| Яндекс Недвижимость, Домклик | проверка, дубли |
| Сделки коллег / Росреестр (если есть) | реальные цены сделок — самый ценный аналог, статус «Сделка» |

Один и тот же объект у разных агентов — это **один** аналог (дубли сверяем по фото, площади, этажу).

## 4. Фильтры на ЦИАН — прямые конкуренты (уровень 1)

- та же **сделка** (продажа / аренда) и тот же **тип** (ПСН, офис, квартира, дом, особняк);
- та же **локация**: тот же ЖК / квартал / посёлок, радиус до 1 км в городе, то же шоссе и удалённость ±5 км за городом;
- **площадь ±30 %** от нашей (у нас 750 м² → ищем 525–975 м²);
- тот же **класс**: ремонт, этажность, отдельный вход, высота потолков — сопоставимые;
- **активные** объявления, опубликованы или обновлены за последние 3 месяца.

Цель — **минимум 5 аналогов уровня 1**. Лучше 6–10.

## 5. Если прямых конкурентов меньше 5 — расширяем по шагам

Идём строго по порядку и останавливаемся, как только набрали 5–8 аналогов. Уровень ставим в столбце «Уровень».

| Шаг | Что расширяем | Уровень |
|---|---|---|
| 1 | Радиус: 1 км → 3 км / соседний район; за городом — соседние посёлки того же шоссе | 2 |
| 2 | Площадь: ±30 % → ±50 % | 2 |
| 3 | Снятые с публикации за 6 месяцев (ЦИАН показывает «снято»; цена на момент снятия близка к цене сделки) | 2 |
| 4 | Другая локация того же класса (соседнее шоссе, другой ЖК того же уровня); снятые за 12 месяцев | 3 |
| 5 | Смежный формат: для особняка в аренду — дома в аренду другой площади; для ПСН — стрит-ритейл того же района | 3 |

Уровень 2 учитывается с весом 0,7, уровень 3 — с весом 0,4 (меняется на листе «Параметры»). Дальние аналоги **не должны** быть большинством: если из 6 аналогов 4 — уровня 3, скажите брокеру, что вывод по цене ненадёжный.

**Не берём:** долю / комнату, объект с обременением или «под снос», объявления без площади или цены, явные ошибки (цена в 3 раза ниже рынка), объекты-дубли.

## 6. Что записываем по каждому аналогу (одна строка)

| Столбец | Как заполнять |
|---|---|
| Уровень | 1 / 2 / 3 (см. выше) |
| Ссылка | ссылка на объявление + **скриншот** в папку «Аналитика» (объявления снимают, скрин — доказательство для собственника) |
| Дата сбора | сегодня |
| Статус | Активно / Снято / Сделка |
| Дней в экспозиции | ЦИАН: «Опубликовано …» — сколько дней висит. Долго висит = цена выше рынка |
| Адрес / ЖК / посёлок | как в объявлении |
| Расстояние до нашего | км по карте |
| Тип / назначение | ПСН, офис, стрит-ритейл, особняк… |
| Площадь, м² | общая |
| Участок, сот. | для домов |
| Этаж / вход | «1 эт., отдельный вход с улицы», «цоколь», «3/5» |
| Ремонт | из списка: Без отделки / Предчистовая / Стандартный / Качественный-дизайнерский / Премиум + мебель |
| Особенности (+/−) | чем лучше или хуже нашего: «+ парковка 10 м/м», «− окна во двор», «+ мебель», «− нет газа» |
| Цена предложения | продажа — ₽ за объект; **аренда — ₽ в месяц за весь объект** |

⚠ **ЦИАН для коммерческой аренды показывает ₽/м² в ГОД.** Пересчёт: ставка × площадь ÷ 12. Пример: 30 000 ₽/м²/год × 200 м² ÷ 12 = 500 000 ₽/мес.

## 7. Корректировки — как сравниваем с нашим объектом

Корректируем **цену аналога к нашему объекту**: «сколько стоил бы аналог, если бы был таким, как наш». Порядок такой, шаблон считает первые три сам:

### 7.1 Торг (автоматически)
Объявление — это цена предложения, сделка проходит дешевле. Снижаем все аналоги со статусом «Активно» и «Снято» на скидку на торг (по умолчанию −5 %; аналог «Сделка» — без торга).
Ориентиры: жильё 3–5 %, коммерция 5–10 %, загородные дома 7–12 %, аренда 3–5 %. Утверждает брокер на листе «Параметры».

### 7.2 Площадь (автоматически) — «эффект масштаба»
Чем больше объект, тем **ниже цена за м²**: большой лот дороже в целом, покупателей на него меньше. Поэтому цену за м² аналога другой площади нельзя переносить напрямую.

Формула: **К = (S нашего / S аналога) ^ b**, где b — коэффициент торможения (отрицательный).

| Сегмент | b |
|---|---|
| Коммерция (ПСН, офисы, стрит-ритейл) | −0,15 |
| Квартиры | −0,10 |
| Загородные дома | −0,20 |

Пример: наш 750 м², аналог 500 м², b = −0,15 → (750/500)^−0,15 = 0,94 → **−6 %** (аналог меньше — его м² дороже, снижаем).
Аналог 1 500 м² → (750/1500)^−0,15 = 1,11 → **+11 %**.
Если площади отличаются меньше чем на 10 % — не корректируем. Если отличаются больше чем в 2 раза — это уже не аналог уровня 1.

### 7.3 Ремонт (автоматически, в рублях за м²)
Ремонт корректируем **не в процентах, а в рублях**: разница стоимости уровней отделки (лист «Параметры»).

| Уровень | Продажа, ₽/м² | Аренда, ₽/м²/мес |
|---|---|---|
| Без отделки | 0 | 0 |
| Предчистовая (white box) | 12 000 | 50 |
| Стандартный ремонт | 35 000 | 150 |
| Качественный / дизайнерский | 70 000 | 300 |
| Премиум + мебель и техника | 120 000 | 450 |

Пример: наш — стандартный (35 000), аналог — white box (12 000) → **+23 000 ₽/м²** к цене аналога.
Цифры — ориентир для Москвы и МО; брокер правит под сегмент (для элитного особняка стоимость отделки выше).

### 7.4 Ручные корректировки (ставит брокер, % + обоснование)
| Фактор | Ориентир |
|---|---|
| Местоположение (метро, трафик, шоссе, престиж посёлка) | ±5–20 % |
| Этаж / вход: цоколь или подвал против 1 этажа с улицы | −20–30 % |
| Этаж для квартир: первый / последний | −5–7 % / −3–5 % |
| Отдельный вход / витрина / первая линия | +10–20 % |
| Парковка, вид, участок, мебель, охрана | ±3–10 % |

Каждую ручную корректировку объясняем одной фразой в столбце «Обоснование» — это потом пойдёт в разговор с собственником.

### 7.5 Правила
- **Общая корректировка больше 30 %** — аналог не учитывается (шаблон ставит «Нет» сам). Значит, он слишком отличается — ищите ближе.
- Вес аналога в итоге тем больше, чем меньше корректировок и ближе уровень.

## 8. Итог (правый верхний блок шаблона)

| Показатель | Как читать |
|---|---|
| Аналогов учтено | меньше 3 — расширяйте поиск |
| Средневзвешенная цена за м² | рыночная цена за м² для нашего объекта |
| Рыночная цена объекта | × наша площадь |
| Диапазон от / до | разброс скорректированных аналогов |
| Коэффициент вариации | ≤ 20 % — выборка однородная, вывод надёжный; больше — пересмотрите аналоги |
| Цена собственника к рынку | +15 % = на 15 % выше рынка |
| Средний срок экспозиции | долго висят (> 90 дней) — рынок не принимает такие цены |

## 9. Что отдаём брокеру

1. Файл в папке «Аналитика» + скриншоты.
2. Коротко в чат брокеру: сколько аналогов, рыночная цена, диапазон, цена собственника к рынку, 2–3 главных аргумента.
3. Для вкладки объекта: файл → Claude с промптом **«Анализ цены по аналогам»** (06_БИБЛИОТЕКА) → ответ → меню **«Вставить стратегию из Claude»**. Аналоги и вывод по цене встанут в разделы 1–2 вкладки, в документ «Маркетинговая стратегия» добавится запись с датой.

## 10. Частые ошибки

- Сравнили ₽/м² в год (ЦИАН, коммерция) с ₽ в месяц.
- Взяли дубли одного объекта у трёх агентов как три аналога.
- Не сделали скриншот — объявление сняли, доказать нечем.
- Взяли аналог в 3 раза больше или меньше «потому что других нет» — это уровень 3, а не 1.
- Забыли торг: сравнили цену собственника с ценами объявлений, а не с ценой сделки.
