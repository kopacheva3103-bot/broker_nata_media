# 10 — Инструкция ассистента: работа в системе эксклюзивов

Для ассистента брокера. Всё, что нужно делать каждый день и каждую неделю, — по шагам.
Меню системы — в таблице вверху: **«МАРКЕТИНГ ОБЪЕКТОВ»**.

## 1. Где что лежит

| Лист / место | Что там | Что делаете вы |
|---|---|---|
| **00_ДЭШБОРД** | сводка по всем объектам и сотрудникам за неделю | смотрите, ничего не вводите |
| **01_ОБЪЕКТЫ** | реестр объектов (ID из CRM, адрес, цена, команда) | дополняете данные, объекты не удаляете |
| **▸ Вкладка объекта** («▸ Осоргино… (ID)») | стратегия объекта: аналоги, цена, сценарии, аудитории, КП, каналы, выводы, план-факт | заполняете разделы, работаете по стратегии |
| **02_ЗАДАЧИ** | задачи по неделям | ставите статус, факт, результат |
| **03_ОБЗВОН_И_КП** | база компаний: звонки, КП, ответы | ведёте каждую компанию строкой |
| **04_КОНТЕНТ** | публикации об объектах | помогаете SMM, если поручено |
| **06_БИБЛИОТЕКА** | промпты для Claude, чек-листы, регламенты | берёте промпты через меню |
| **Google Диск → 01_ОБЪЕКТЫ** | папки объектов: «Аналитика», «КП и презентации», «Отчёты» | кладёте файлы по объекту |
| **Google Диск → папка объекта → Отчёты** | отчёты клиенту: системные и старые (до системы) | старый отчёт кладёте сюда PDF — утром (или по «Обновить документы») он отметится в 10_АРХИВ_ОТЧЁТОВ как «Старая форма» |
| **Google Диск → 04_ВХОДЯЩИЕ** | «приёмник» для новых презентаций | кладёте презентации новых объектов |
| **Яндекс Диск → «Объекты на ДОГОВОРЕ»** | фото и видео объектов | проверяете, что у каждого объекта есть папка |

**Цвет заголовков столбцов:** тёмный — вводится вручную; серо-голубой — формула (не трогать); светло-серый — заполняет система (не трогать).

## 2. Начало дня (15 минут)

1. **Письмо «План на сегодня»** приходит в будни в 9:00 на вашу почту: задачи со сроком сегодня и просроченные, звонки и повторные контакты, аудитории без базы. Работайте по нему.
2. **Google Календарь:** ваши задачи со сроками стоят в вашем календаре на дату срока. Выполнили задачу в таблице — в календаре появится «✓» (в течение часа).
3. **02_ЗАДАЧИ:** включите фильтр по столбцу «Исполнитель» = вы. Порядок работы: сначала просроченные (красные), потом срок сегодня, потом остальные задачи недели.
4. **03_ОБЗВОН_И_КП:** отфильтруйте «Когда» (дата следующего шага) ≤ сегодня — это звонки и повторные контакты на сегодня.

## 3. Задачи (02_ЗАДАЧИ)

Каждая строка — одна задача по объекту. Задачи ставятся на оперативке, из стратегии Claude, планом недели или системой.

| Столбец | Что делать |
|---|---|
| **Статус** | Запланировано → В работе → **Выполнено**. Не успели — **Перенесено** (система сама создаст копию на следующую неделю, старая строка остаётся в истории). Не нужно — **Отменено** |
| **Факт (вручную)** | сколько сделано (документов, компаний, писем). По **звонкам и КП факт считается сам** из 03_ОБЗВОН_И_КП — вручную не пишите |
| **Результат / комментарий** | коротко и по делу: что сделано, ссылка на файл. Это видит собственник в отчёте |
| **Срок** | меняете, только если руководитель согласовал |

**Правила:**

- Задачу формулируем так, чтобы её можно было показать собственнику.
- Строки **не удаляем** — ненужное ставим «Отменено».
- Новую задачу можно добавить в конец листа: ID объекта, блок, задача, исполнитель, срок — остальное система заполнит.

## 4. Работа с базой (03_ОБЗВОН_И_КП) — главное

**Одна строка = одна компания (или контакт) по одному объекту.**

### Как вести строку
1. **ID объекта** — выберите из списка.
2. **Аудитория** — выберите из списка (он появляется после выбора объекта; это аудитории из вкладки объекта). Нужной нет — сначала добавьте аудиторию во вкладку объекта (раздел 4) или скажите руководителю.
3. **Компания, сайт, контакт** — «ЛПР, должность, телефон, email». Если система подсказала «Компания уже в работе по другому объекту» — не звоните второй раз без согласования с руководителем.
4. **Соответствие объекту** — Подходит / Уточнить / Не подходит + «Почему».
5. После звонка — **Дата звонка** и **Итог звонка** (кто ответил, что сказали, что договорились).
6. Отправили КП — **Дата КП** и **Какое КП** (клиенту / партнёру / презентация / письмо).
7. Получили ответ — **Ответ** (Интересно / Просят позже / Не интересно / Переслали ЛПР) — дата ответа ставится сама.
8. Всегда назначайте **Следующий шаг** и **Когда** — иначе компания «потеряется».
9. **Повторный контакт ставится сам:** если КП отправлено, ответа нет 3 рабочих дня и шаг не назначен — система пишет «Повторный контакт: получили ли КП, есть ли вопросы» на сегодня. Позвоните / напишите и обновите строку.
10. Компания реально заинтересовалась — заведите её в CRM TopenLab и поставьте галочку **«Передан в CRM»** — в карточку CRM уйдёт история работы.

### Важно
- Звонки и КП считаются в отчёт собственнику и в факт задач **только если внесены в этот лист** с датами. Не внесли — работы «не было».
- Вносите **в тот же день**.
- Название аудитории — только из списка: по нему считаются цифры во вкладке объекта («В базе / КП / Интересно») и в отчёте собственнику.

## 5. Новый объект

1. Положите презентацию в **Google Диск → 04_ВХОДЯЩИЕ**, имя файла: **«ID Название.pdf»** (ID из CRM, например «144853475 Осоргино особняк.pdf»). Нет ID — просто название.
2. В течение 10 минут система создаст объект в 01_ОБЪЕКТЫ, вкладку объекта и папку на Google Диске, а файл переложит в «КП и презентации».
3. **Вам придёт задача:** проверить папку объекта на **Яндекс Диске** («Объекты на ДОГОВОРЕ») — есть ли фото и видео; нет — создать папку с названием объекта и загрузить материалы.
4. Проверьте в 01_ОБЪЕКТЫ адрес, площадь, цену, тип и сделку — дополните, чего нет.
5. Когда объект выйдет в рекламу — скопируйте в TopenLab ссылку на «Отчёт по рекламе» и вставьте через меню «➜ Вставить ссылки на отчёты по рекламе CRM» (можно сразу несколько — объект система определит сама). Пока ссылки нет, вам висит задача об этом. Из неё в отчёт клиенту сами попадут площадки, просмотры, избранное, обращения и ссылка на ЦИАН. Проверка: меню «➜ Проверить отчёты по рекламе CRM».

## 6. Работа с Claude (без доплат, через подписку)

Все промпты — в меню **«➜ Промпт для Claude по объекту»**:

1. Встаньте на вкладку объекта (или строку объекта), откройте меню.
2. Выберите промпт (и аудиторию, если есть такое поле) → **«Скопировать»** → **«Открыть Claude»**.
3. В Claude: новый чат, **включите поиск в интернете**, вставьте текст. Если Claude задаёт вопросы — ответьте (или спросите руководителя).
4. Ответ, который нужно перенести в систему, копируйте **целиком** → меню **«➜ Вставить стратегию из Claude»** → выберите объект → вставьте → **«Проверить»** → **«Вставить во вкладку»**.

| Промпт | Когда | Куда попадает результат |
|---|---|---|
| **Целевые аудитории объекта — для вставки** | нет аудиторий или нет базы по аудитории ★★★ | аудитории — во вкладку; **компании — сразу в 03_ОБЗВОН_И_КП** |
| **Скрипт звонка и письма** | перед обзвоном новой аудитории (выберите аудиторию) | используете сами: звонок, возражения, письмо, мессенджер |
| **Портрет ЛПР и выход на него** | трудная аудитория, не проходите секретаря | используете сами |
| **Анализ цены по аналогам** | после сбора аналогов (см. инструкцию 09) | аналоги и цена — во вкладку |
| **Объявление для ЦИАН / Авито** | новое объявление или обновление | текст для площадок |
| **КП клиенту и партнёру** | нужно КП под аудиторию | текст КП |
| **Стратегия объекта — для вставки во вкладку** | новый объект (обычно делает руководитель) | вся вкладка + задачи |

## 7. Анализ конкурентов (аналоги)

Подробно — **инструкция «09 — Анализ конкурентов»** в 03_ИНСТРУКЦИИ. Коротко: копия шаблона «Анализ аналогов» из 02_ШАБЛОНЫ → в папку объекта «Аналитика» → аналоги с ЦИАН (ссылка + скриншот) → корректировки считаются сами → файл в Claude с промптом «Анализ цены по аналогам» → «Вставить стратегию из Claude».

## 8. Фото и видео

- Храним на **Яндекс Диске → «Объекты на ДОГОВОРЕ»**, одна папка на объект, в названии — название объекта как в системе.
- В Google Диск фото и видео **не переносим**.
- Новая съёмка — загрузить в папку объекта в тот же день.

## 9. Неделя

| День | Что делаем |
|---|---|
| **Понедельник** | оперативка → задачи вносятся через «➜ Внести задачи с оперативки»; «➜ Создать план недели» (если поручено) — в план сами попадут звонки / КП и задачи «База «аудитория»» по аудиториям ★★★, где мало компаний |
| **Каждый день** | письмо 9:00 → задачи → обзвон и КП → всё внести в 03_ОБЗВОН_И_КП в тот же день |
| **Пятница до 19:00** | закрыть статусы всех задач недели, внести факт и результат, проверить, что все звонки и КП внесены. **В 20:00 система сама отправляет отчёты собственникам в CRM** — что не внесено, в отчёт не попадёт |

## 10. Что нельзя

- Удалять строки в листах и удалять объекты (объект удаляет только руководитель).
- Менять серые и серо-голубые столбцы (формулы и системные поля).
- Менять ID объекта (он из CRM).
- Писать аудиторию «своими словами» — только из списка.
- Отправлять партнёру КП с нашими контактами или контактами собственника — для партнёра только «КП партнёру».
- Публиковать точный адрес, если во вкладке объекта есть ограничение собственника.

## 11. Частые вопросы

- **Нет нужной аудитории в списке** → добавьте её во вкладку объекта (раздел 4 «Целевые аудитории») → в строке базы выберите объект заново — список обновится (или сам утром).
- **Задача не появилась в календаре** → подождите до часа; проверьте, что указан «Срок».
- **Звонки не посчитались в задаче** → в 03_ОБЗВОН_И_КП должны быть заполнены ID объекта и «Дата звонка» / «Дата КП» на этой неделе.
- **Меню не видно** → обновите страницу (F5).
- **Что-то сломалось / непонятно** → напишите руководителю, приложите скриншот.
