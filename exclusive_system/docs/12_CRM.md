# Связь с CRM TopenLab

Что делает: когда ассистент ставит в **03_ОБЗВОН_И_КП** галочку **«Передан в CRM»**, система находит карточку клиента в TopenLab по телефону из столбца «Контакт» (сначала среди заявок, потом среди объектов) и добавляет в неё **заметку**: объект, компания, аудитория, дата и итог звонка, КП, ответ, следующий шаг, кто вёл. Результат виден в столбце **«CRM»**.

Ограничение API TopenLab: **создавать карточки он не умеет**. Порядок такой:
1. Заведите клиента в TopenLab вручную (с тем же телефоном, что в «Контакт»).
2. Поставьте галочку «Передан в CRM» — заметка добавится сама.
3. Если в «CRM» написано «карточки … нет» — заведите карточку, затем снимите и снова поставьте галочку (или меню **Отправить отмеченные в CRM**).

Поиск в API — не чаще раза в 6 секунд: при одной-двух галочках всё происходит сразу, при массовой отметке — меню **➜ Отправить отмеченные в CRM**.

## Подключение (один раз)

1. Ключ API TopenLab — тот же, что в вашей связке Telegram → TopenLab (`TOPNLAB_API_KEY`), или новый из TopenLab (Настройки системы → Интеграции / API).
2. ID пользователя TopenLab, от имени которого пишутся заметки (Настройки системы → Пользователи).
3. Таблица → **Сервис → Подключить CRM TopenLab** → ключ, ID пользователя, при желании телефон любой существующей карточки для проверки → **Сохранить и проверить**. Ключ хранится в свойствах скрипта, в таблице его не видно.

## Что пишется в столбец «CRM»

| Значение | Что значит |
|---|---|
| ✓ заметка 26.09.2026 · заявка 123 | Заметка добавлена в карточку |
| ⚠ карточки с телефоном … нет — заведите в CRM | Заведите карточку, затем снимите и поставьте галочку |
| ⚠ нет телефона в «Контакт» | Впишите телефон в «Контакт» (+7 … или 8 …) |
| … ждёт: меню «Отправить отмеченные в CRM» | Отмечено много строк сразу — запустите меню |
| ⚠ ошибка CRM 401/403 | Ключ не принят — проверьте в «Подключить CRM TopenLab» |
