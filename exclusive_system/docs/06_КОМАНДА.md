# Инструкция для ассистента и SMM

Цвет заголовка: **тёмный** — вводите вы; **серо-голубой** — формула (не трогать); **светло-серый** — заполняет скрипт. ID, неделю, срок, автора и дату скрипт ставит сам. Ничего не удаляйте — меняйте статус.

## Ассистент: 03_ОБЗВОН_И_КП

Одна строка = одна компания по одному объекту. Заполняйте **в тот же день**:
1. ID объекта (из списка), **Аудитория** — так же, как во вкладке объекта (тогда цифры по аудитории посчитаются сами), компания, сайт, контакт.
2. Соответствие объекту и почему.
3. Позвонили — **Дата звонка** и итог. Отправили КП — **Дата КП** и какое (клиенту / партнёру без контактов).
4. Ответили — **Ответ** (дата ответа поставится сама), следующий шаг и когда.
5. Реально заинтересованный → заведите в CRM и отметьте **Передан в CRM**.

Звонки, КП и ответы сами идут в факт задач, дэшборд, вкладку объекта и отчёт клиенту («обзвонено N компаний, направлено N КП»). Контакты в отчёт не попадают.

## Задачи и календарь

Задачи со сроком приходят приглашением в ваш Google Календарь (на email из 07_СПРАВОЧНИКИ). Закрыли задачу в 02_ЗАДАЧИ — в календаре появится «✓»; отменили или перенесли — событие уберётся.

## Ассистент: 02_ЗАДАЧИ

Свои задачи недели: в пятницу поставьте статус (Выполнено / Не выполнено / Перенесено) и коротко «Результат» — он попадает в отчёт. Факт по звонкам / КП / ответам вводить не нужно — считается сам; для остальных единиц — «Факт (вручную)».

## SMM: 04_КОНТЕНТ

Одна строка = одна публикация: объект, тема, площадка, формат, цель (найти покупателя / показать собственнику / бренд), сценарий (текст или ссылка), статус. После публикации — статус «Опубликовано» (дата поставится сама), **ссылка**; через 2–3 дня — просмотры, охват, сохранения, заявки. **Просмотры Telegram и YouTube обновляются сами** по ссылке (меню «Обновить просмотры Telegram / YouTube» или каждое утро, если включено ежедневное обновление). Instagram и Threads, а также охват, сохранения и заявки — вручную. Сценарий рилс: встаньте во вкладку объекта → **Меню → Промпт для Claude по объекту → «Сценарий рилс»** → скопировать в Claude.

## Вкладки объектов

Разделы 1–7 заполняет вся команда: аналоги, сценарии, аудитории, КП, каналы, решения. Нужна ещё строка — вставьте строку внутри раздела. Все правки с автором пишутся в 09_ИСТОРИЯ.
