# L. Возможные ошибки и как их исправить

| Симптом | Причина | Что сделать |
|---|---|---|
| Нет меню «МАРКЕТИНГ ОБЪЕКТОВ» | Скрипт не сохранён / страница не обновлена | Сохраните проект Apps Script, обновите таблицу (F5) |
| «This app isn't verified» | Первый запуск своего скрипта | «Дополнительные настройки» → «Перейти в проект» → «Разрешить» |
| `#REF!` на весь столбец | В серо-голубой (формульный) столбец что-то ввели | Удалите значение — формула восстановится |
| Вкладка объекта не появилась | Нет ID или названия; вставили строку большим блоком | Заполните оба поля или **➜ Обновить (ID, вкладки, строки)** |
| ID не проставился | Вставка большого блока / триггер не установлен | **➜ Обновить**; если повторяется — «Установить / обновить систему» |
| В 01 ячейка ID красная | Нет ID или дубль | Введите номер из CRM |
| «⚠ нет объекта» в журнале | ID объекта не из 01 | Выберите из списка |
| Установщик: «столбцы переставлены» | Вставили/переставили столбец журнала | Верните порядок (docs/02_ПОЛЯ.md). Свои столбцы — только справа |
| Цифры по аудитории во вкладке 0 | Аудитория в 03 написана иначе | Пишите одинаково (скопируйте из вкладки) |
| Факт задачи не считается | Единица не звонков / КП / ответов / публикаций, или нет даты в 03/04 | Для других единиц — «Факт (вручную)» |
| Неделя не выбирается | Вне диапазона справочника | 08_НАСТРОЙКИ: «Начало учёта недель» раньше / больше будущих недель |
| Отчёт: «Выберите объект и неделю» | Пустые B3/B4 в 05 | Выберите из списков |
| В отчёте «—» / «Задачи на неделю не внесены» | Нет задач с галочкой «В отчёт» на эту неделю | Проверьте 02_ЗАДАЧИ |
| Хочу изменить вид отчёта | — | Правьте «Шаблон еженедельного отчёта» в `02_ШАБЛОНЫ`; метки `{{…}}` не удалять, строки таблиц с `{{PLAN_ROWS}}`, `{{LEADS_ROWS}}`, `{{NEXT_ROWS}}` оставить |
| Удалили шаблон | — | Очистите «ID шаблона отчёта» в 08 — создастся новый |
| «Обновить PDF» ничего не нашёл | Отчёт ещё не создавался | Сначала «Создать отчёт клиенту» |
| Сотруднику нет доступа к папке | Email не в справочнике | 07_СПРАВОЧНИКИ → Email → «Установить / обновить систему» |
| После обновления кода вкладки старого вида | Вкладки пересобираются отдельно | **Сервис → Обновить все вкладки объектов** (данные сохраняются) |
| Календарь: «Нет email у …» | Впишите email сотрудника в 07_СПРАВОЧНИКИ |
| Приглашения не приходят | Задача без срока, старше 14 дней или уже выполнена до первой синхронизации |
| Просмотры Telegram не обновились | Канал закрытый или ссылка не на пост (нужна t.me/канал/123) |
| «YouTube не подключён» | Редактор Apps Script → Сервисы ＋ → YouTube Data API v3 → Добавить |
| «Внести задачи с оперативки»: объект не найден | В первом столбце — ID из 01_ОБЪЕКТЫ (или точное название) |
| Превышено время выполнения | Медленный Google | Запустите ещё раз — данные сохраняются |
