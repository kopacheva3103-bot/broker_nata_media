# L. Возможные ошибки и как их исправить

| Симптом | Причина | Что сделать |
|---|---|---|
| Нет меню «УПРАВЛЕНИЕ ЭКСКЛЮЗИВАМИ» | Скрипт не сохранён или страница не обновлена | Сохраните проект Apps Script, обновите таблицу (F5). Проверьте, что файл `13_Menu` есть |
| «Требуется авторизация» / «This app isn't verified» | Первый запуск своего скрипта | «Дополнительные настройки» → «Перейти в проект (небезопасно)» → «Разрешить». Это ваш скрипт |
| `#REF!` на весь столбец, «Результат массива не был развернут…» | В серо-голубой (формульный) столбец что-то ввели | Найдите и удалите значение в этом столбце (Ctrl+Z или Delete) — формула восстановится |
| ID не проставился, неделя пустая | Не сработал триггер (вставка большого блока, триггер не установлен, ошибка доступа) | **➜ Обновить статистику** — проставит ID и значения по умолчанию. Если повторяется — **Сервис → ⚙ Установить / обновить систему** (переустановит триггер) |
| В 01 ячейка ID красная, «НЕТ ID» / «ДУБЛЬ ID» | ID не введён или повторяется | Введите номер объекта из CRM. Без ID объект не попадает в статистику, дэшборд и отчёты |
| Объект показывает «⚠ нет объекта» в 03/04/06 | В «ID объекта» значение, которого нет в 01 | Выберите ID из списка. Название объекта ключом не является |
| Установщик пишет «столбцы переставлены или переименованы вручную» | В журнале вставили/переставили/переименовали столбец | Верните порядок (см. docs/02_ПОЛЯ.md). Свои столбцы — только справа от журнала |
| В выпадающем списке нет нужного значения | Значения нет в 08_СПРАВОЧНИКИ | Добавьте его в нужный столбец 08 (в конец списка) |
| Переименовали статус — перестали считаться выполненные / просрочки | Переименовали «Класс», удалили строку статуса или в старых строках осталось прежнее название | Названия менять можно, столбец «Класс» (OPEN/DONE/…) — нет. После переименования замените старое название в журналах (Ctrl+H) |
| Неделя не выбирается в 06 / 07 / 09 | Неделя вне диапазона справочника | 10_НАСТРОЙКИ → «Начало учёта недель» раньше, «Сколько будущих недель» больше |
| Отчёт: «Выберите объект и неделю» | Пустые B3/B4 на 07 | Выберите из списков |
| Отчёт: «Отчёт за эту неделю уже есть» | Повторное создание | «Да» — новая версия; старая останется в 13 со статусом «Заменён» |
| В отчёте попало внутреннее | Внутренний текст записан в «Факт»/«Обратная связь»/«Вывод» | Перепишите поле для клиента или снимите «В отчёт клиенту»; внутреннее пишите в «Комментарий» |
| В отчёте «—» вместо раздела | Нет данных за неделю | Нормально. Проверьте, что действия этой недели в статусе «Выполнено» |
| «Создать PDF» ничего не нашёл | Отчёт ещё не создавался для этого объекта/недели | Сначала **➜ Создать отчёт** |
| Ошибка Drive «Нет доступа к папке» у ассистента | Папка системы не расшарена | Впишите email ассистента в 10_НАСТРОЙКИ и переустановите, или расшарьте папку «СИСТЕМА ЭКСКЛЮЗИВОВ» вручную (Редактор) |
| Удалили шаблон отчёта/стратегии | — | Очистите ID шаблона в 10_НАСТРОЙКИ — при следующем отчёте создастся новый |
| Хочу изменить вид отчёта | — | Правьте документ «Еженедельный отчёт по продаже объекта» в `03_TEMPLATES`: шрифты, логотип, порядок разделов. Placeholders `{{…}}` не удаляйте. Список-placeholders (`{{DONE}}`, `{{CONVERSIONS}}`…) должны стоять отдельным абзацем |
| Предупреждение «Пора подготовить отчёт» не исчезает | Дата последнего отчёта ставится только при «Создать отчёт» | Создайте отчёт через меню, а не вручную |
| Дашборд/статистика «думают» долго | Много тысяч строк, открытые диапазоны | Нормально до ~10–20 тыс. действий. Дальше — архивировать старые годы в копию таблицы |
| «Превышено максимальное время выполнения» при установке | Медленный Google | Запустите установку ещё раз — она продолжит с сохранением данных |
| Формулы показываются текстом | В столбец поставлен формат «Текст» и формула вставлена вручную | Переустановка системы вернёт формулы |
| Самопроверка ✗ на «все объекты…» | Кроме тестовых есть реальные данные | Эти проверки рассчитаны на таблицу только с тестовыми данными |
| Ежедневная сводка не приходит | Не включена или пуст email | 10_НАСТРОЙКИ → email → **Сервис → Включить ежедневную сводку**. Письмо приходит, только если есть предупреждения |
