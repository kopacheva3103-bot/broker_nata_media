## Этап 2 — Claude внутри таблицы

**Кнопка «Спросить Claude»** (боковая панель): выбрать объект и промпт из 06_БИБЛИОТЕКА (анализ цены, сценарии и неочевидные аудитории, портрет, КП, скрипт звонка, сценарий рилс) → скрипт сам подставит данные вкладки объекта → ответ можно одним нажатием вставить в нужный раздел. Каждый запрос и ответ пишутся в журнал: кто, когда, по какому объекту.

**Оперативка → задачи**: вставить расшифровку Zoom (или ссылку на Google Doc с ней) → Claude раскладывает решения и задачи по объектам → вы проверяете → задачи попадают в 02_ЗАДАЧИ, решения — в раздел 7 вкладки.

**Google Календарь**: задачи с исполнителем и сроком — событием в календарь исполнителя; поставить задачу коллеге = строка в 02 с его именем.

### Важно про оплату Claude

Подписки Claude (ваш Max, базовые у сотрудников) — это чат claude.ai; они **не дают доступ из таблицы**. Для кнопки нужен отдельный **API-ключ** (console.anthropic.com, аккаунт организации, оплата по факту использования, можно поставить месячный лимит). Ключ хранится в свойствах скрипта — сотрудники его не видят, все пользуются одной кнопкой под своими аккаунтами Google, а каждый запрос логируется с автором.

Ориентир стоимости: основная модель (Claude Opus 5) — $5 за 1 млн входящих токенов и $25 за 1 млн исходящих; один типичный запрос (данные вкладки + ответ на 1–2 страницы) — порядка нескольких рублей–десятков рублей; при ~20–40 запросах в день — примерно несколько тысяч рублей в месяц. Claude через API умеет искать в интернете (веб-поиск) — для подбора компаний и проверки данных.

## Этап 3 — статистика соцсетей

Сейчас SMM вносит цифры вручную в 04_КОНТЕНТ (ссылка, просмотры, охват, сохранения, заявки). Автоматизация по мере готовности аккаунтов:
- **YouTube Shorts** — YouTube Data API, проще всего (нужен доступ к каналу).
- **Instagram и Threads** — Meta Graph API: профессиональный аккаунт, связанная страница Facebook, приложение Meta.
- **Telegram** — просмотры постов канала через бота-администратора (ограниченно).
Скрипт раз в сутки обновит просмотры и охват по ссылкам из 04_КОНТЕНТ.
