# Следующие этапы

Этап 1 (готов): вкладки объектов со стратегией, план-факт, обзвон и КП, контент, дэшборд, отчёт клиенту в вашем формате, библиотека, история изменений.

## Сделано без API (работает на ваших подписках Claude)

- **Промпт для Claude по объекту** — промпт из библиотеки + все данные вкладки объекта одним текстом, копируется в claude.ai.
- **Оперативка → задачи** — Claude по промпту «Оперативка → задачи» превращает расшифровку Zoom в таблицу; меню «Внести задачи с оперативки» разносит задачи в 02_ЗАДАЧИ и решения во вкладки.
- **Google Календарь** — задачи со сроком событиями, исполнителям приглашения; «✓» для выполненных, удаление для отменённых и перенесённых; можно включить ежедневно.
- **Просмотры Telegram** (публичный канал) — автоматически; **YouTube / Shorts** — после подключения сервиса «YouTube Data API v3» в редакторе Apps Script (Сервисы ＋, один раз).

## Отложено — кнопка «Спросить Claude» в таблице

Ответ Claude прямо в таблице без копирования, с журналом запросов. Требует отдельного API-ключа Anthropic (подписки Claude его не включают), оплата по факту: основная модель Claude Opus 5 — $5 за 1 млн входящих и $25 за 1 млн исходящих токенов, около $0,1 за типичный запрос. Подключим, когда решите.

## Этап 3 — статистика соцсетей

Сейчас SMM вносит цифры вручную в 04_КОНТЕНТ (ссылка, просмотры, охват, сохранения, заявки). Автоматизация по мере готовности аккаунтов:
- **YouTube Shorts** — YouTube Data API, проще всего (нужен доступ к каналу).
- **Instagram и Threads** — Meta Graph API: профессиональный аккаунт, связанная страница Facebook, приложение Meta.
- **Telegram** — просмотры постов канала через бота-администратора (ограниченно).
Скрипт раз в сутки обновит просмотры и охват по ссылкам из 04_КОНТЕНТ.
