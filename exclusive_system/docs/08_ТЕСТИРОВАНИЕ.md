1. **Сервис → Загрузить пример** → **Сервис → Запустить самопроверку** («Да» — проверить и создание Google Doc / PDF).
2. Лист **99_САМОПРОВЕРКА**: листы и настройки на месте, триггер установлен, нет `#REF!/#ERROR!/#NAME?` в журналах, дэшборде, отчёте и вкладках, библиотека заполнена; на примере — стратегия 100 %, звонков за 2026-W38 = 8, КП = 2, КП за 2026-W39 = 9 (авто), отчёт за 14.09–18.09: 5 пунктов «Выполнение плана», 3 пункта «План работы», нет контактов из обзвона, в Doc не осталось меток `{{…}}`.

## В репозитории (без Google)

```
node tools/check_formulas.js   # все 120+ формул: скобки, кавычки, токены, известные функции
node tools/smoke_test.js       # установка, пример, пересборка вкладки, план недели, перенос, onEdit, история,
                               # промпт по объекту, оперативка → задачи, календарь, Telegram, Instagram/Threads, импорт постов Threads,
                               # CRM TopenLab (имитация API)
node tools/gen_docs.js         # docs/02_ПОЛЯ.md и 03_ФОРМУЛЫ.md из схемы
sh tools/build_dist.sh         # dist/Code.gs — весь код одним файлом
```

Новые конструкции формул (ARRAY_CONSTRAIN+SORT+FILTER, нумерация строк LET+SEQUENCE, COUNTIF по составному ключу, HYPERLINK в ARRAYFORMULA, сравнение недель) проверены в настоящей Google Таблице.
