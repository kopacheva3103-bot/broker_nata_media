# Тестирование (п.24 ТЗ)

## Как запустить

1. Чистая установка → **Сервис → Загрузить тестовые данные** → **Сервис → Запустить самопроверку** (ответ «Да» — проверить и Google Docs / PDF).
2. Результат — лист **99_САМОПРОВЕРКА** (97 проверок, зелёные ✓ / красные ✗ с ожидаемым и полученным значением).

Даты тестовых данных строятся от текущей недели, поэтому тест воспроизводим в любой день:
**M** — понедельник текущей недели, **P = M − 7** — отчётная неделя, **Q = P − 7**.

ID тестовых объектов имитируют номера из CRM: **4501** Остров, **4502** Аносино Парк, **4503** Павловы Озёра.

Есть внутреннее действие (скрыто из отчёта), внутренний комментарий, просроченная задача, задача без ответственного, запланированное действие с прошедшей датой |

## Что проверено до передачи

- Весь код загружается без синтаксических ошибок; все **426 формул** генерируются, у всех сбалансированы скобки и кавычки, нет неразвёрнутых ссылок, используются только функции Google Sheets (`node tools/check_formulas.js`).
- Тестовые данные прогоняются тем же кодом `loadTestData_` на макете таблицы (`node tools/build_test_workbook.js`).
- Ключевые приёмы формул проверены в настоящем Google Sheets (временная таблица, затем удалена): ISO-недели из дат, заголовок `{"…";ARRAYFORMULA(…)}`, `SUMIF/COUNTIF` по склеенным ключам внутри ARRAYFORMULA и LET, `QUERY` по массиву с подсчётом и суммой, `TEXT` с датами, сборка предупреждений из нескольких `FILTER` со строками-константами и сортировкой, список недель через `SEQUENCE`, ключи каналов через `UNIQUE`+`VLOOKUP`, `COUNTIFS` по галочкам, `INDEX(SORT(FILTER…))`, `REGEXEXTRACT` подписи. Все дали ожидаемые значения.
- **Не проверено вживую**: полный прогон установки и самопроверки внутри Apps Script (в этой среде нет доступа к исполнению Apps Script). Это и есть первый шаг после установки — самопроверка покажет любую проблему конкретной строкой.
