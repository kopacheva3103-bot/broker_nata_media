# K. Как завести первый реальный объект

Пример: эксклюзив на дом в КП «Остров».

## 1. 01_ОБЪЕКТЫ — новая строка

Заполните: **ID объекта** — номер объекта из CRM (обязательно, как в CRM, без изменений), **Название объекта** (как будет в отчёте клиенту), **Адрес**, **ЖК / поселок**, **Тип объекта**, **Категория**, **Площадь**, **Количество комнат**, **Цена**, **Тип сделки**, **Дата подписания** и **Дата окончания эксклюзива**, **Ответственный**, **Ассистент**, **Ссылка на CRM**, **Приоритет**, **Температура**, **Целевой покупатель**, **Основной канал продаж**.

Сразу после ввода скрипт:
- проверит ID: если он пустой или уже есть у другого объекта — ячейка станет красной и появится предупреждение;
- поставит статус «Новый»;
- создаст строку в **02_СТРАТЕГИЯ**;
- запишет первую цену в **12_ИСТОРИЯ**.

Сами посчитаются: цена за м², дни в продаже, дни без активности, следующий отчёт, флаг активности. Объект появится в 05, 07, 09, 11 без каких-либо правок.

Ошиблись в ID? Просто исправьте его в 01 — скрипт заменит старый ID во всех связанных листах и в названиях папок.

## 2. 02_СТРАТЕГИЯ — краткая версия

В строке объекта коротко (1–3 предложения на поле): цель, целевая цена и диапазон, позиционирование, 3 аудитории, мотивы, возражения и ответы, конкуренты, преимущества и слабые стороны, что нельзя говорить публично, ключевой аргумент, сценарий, каналы, CRM-база, контент/outbound, план продвижения, гипотезы. Поставьте **Дату последнего пересмотра**.

Руководитель ставит **Статус стратегии = «Утверждена»**.

## 3. Google Doc стратегии и папки

Встаньте на строку объекта → **➜ Открыть стратегию**. Создастся документ «Остров — Стратегия продажи» в `01_STRATEGIES/Остров (4517)` с уже подставленной краткой версией; ссылка запишется в 01 и 02. Дальше углубляйте стратегию в документе.

(Папка отчётов `02_WEEKLY_REPORTS/Остров (4517)` создастся при первом отчёте. Для всех объектов сразу — **Сервис → Создать папки и стратегии для всех объектов**.)

Когда объект реально начал продаваться — поменяйте статус на «Активная продажа».

## 4. План первой недели

**➜ Создать план недели** → в 06 появятся строки KPI по умолчанию. Допишите цель недели и 3–5 задач («Подготовить презентацию», «Рассылка по базе», «Обзвон брокеров», «Опубликовать на ЦИАН»), ответственных и дедлайны.

## 5. Работа

Действия → 03, покупатели → 04. Через неделю: **07_ОТЧЕТ** → объект + неделя → **➜ Создать отчёт**.

## Если объект уже продаётся давно

Перенесите в 03 одним действием-сводкой ключевые цифры за прошлый период (например, «Итоги продаж до ведения системы», контакты/показы суммой, дата — последний день перед стартом), а в 04 — живых лидов со статусами. Историю переписки не переносите — она в CRM.
