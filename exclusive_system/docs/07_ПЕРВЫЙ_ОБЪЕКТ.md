# K. Как завести объект

1. **01_ОБЪЕКТЫ** — новая строка: **ID из CRM** и **название** (короткое — так будет называться вкладка). Сразу появится вкладка «▸ Название (ID)», статус «В работе», ссылка «открыть».
2. Там же: тип, сделка, адрес (как в договоре — идёт в отчёт), площадь, цена, ответственный, ассистент, SMM, заказчик, № и дата договора, ссылка на CRM. Есть своя папка на Диске — ссылку в «Папка объекта».
3. Во вкладке: аналоги → цена → сценарии (выберите чек-лист) → аудитории → КП → каналы. Смотрите «Стратегия заполнена».
4. **Меню → Создать план недели** — задачи недели; ассистент начинает 03, SMM — 04.
5. В понедельник — отчёт клиенту.

Ошиблись в ID — исправьте в 01: ID заменится в задачах, обзвоне, контенте, архиве, вкладке и в имени папки. Переименовали объект — переименуется вкладка.

## Пример

**Сервис → Загрузить пример (ЖК Время · Лермонтовская 1)** — объект по реальным материалам (анализ, отчёт № 5, таблица медцентров): заполненная стратегия, задачи 14–18.09 и 21–25.09, 22 компании обзвона, контент. Заказчик, № договора и ссылки на файлы в примере условные (код хранится в публичном репозитории) — замените в таблице. Пример можно удалить: строки с ID «ВРЕМЯ-1» в 01–04 и вкладку.

## Объект уже в работе давно

Внесите стратегию во вкладку, а прошлую работу — одной задачей-итогом в 02 («Итоги работы до ведения системы») и строками 03 по уже обзвоненным компаниям с их датами.
