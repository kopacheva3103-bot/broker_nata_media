# K. Как завести объект

## Через презентации — папка «04_ВХОДЯЩИЕ — новые объекты»

Положите презентацию / КП объекта (PDF, PowerPoint, Word, Google Презентация) в папку **СИСТЕМА ЭКСКЛЮЗИВОВ / 04_ВХОДЯЩИЕ — новые объекты**. Система (меню **➜ Разобрать папку «Входящие»** или сама каждые 10 минут при включённом автообновлении):
- находит объект по ID в начале имени файла (`4801 Остров.pdf`) или по названию; если объекта нет — заводит его: название — из имени файла, **адрес, площадь, цена, тип, сделка — из текста презентации** (проверьте их в 01_ОБЪЕКТЫ); статус «Подготовка»;
- без ID из CRM даёт временный ID **НОВ-001** — замените на ID из CRM в 01_ОБЪЕКТЫ, он обновится везде;
- создаёт вкладку и папку объекта на Диске и **переносит файл в «КП и презентации»**; файл появляется в «Документы объекта».
Совет: называйте файл «ID Название» — тогда объект определяется без ошибок.

## Сразу много объектов — «➜ Загрузить объекты списком»

Скопируйте строки из CRM / Excel / Google Таблицы (столбцы по порядку: ID из CRM | Название | Тип | Сделка | Адрес | Площадь, м² | Цена | Статус | Ответственный | Заказчик | № договора | Дата договора | Ссылка на CRM; обязательны только ID и название) → меню **➜ Загрузить объекты списком** → вставить → «Проверить» → «Загрузить». Объекты добавятся в 01_ОБЪЕКТЫ, у каждого появится вкладка; объекты с уже существующим ID не дублируются — у них дополнятся пустые поля. Вставлять блок прямо в 01_ОБЪЕКТЫ не нужно (там есть столбцы с формулами).

## Один объект

1. **01_ОБЪЕКТЫ** — новая строка: **ID из CRM** и **название** (короткое — так будет называться вкладка). Сразу появится вкладка «▸ Название (ID)», статус «В работе», ссылка «открыть».
2. Там же: тип, сделка, адрес (как в договоре — идёт в отчёт), площадь, цена, ответственный, ассистент, SMM, заказчик, № и дата договора, ссылка на CRM. Есть своя папка на Диске — ссылку в «Папка объекта» (или назовите папку в 01_ОБЪЕКТЫ на Диске так же, как объект, — найдётся сама). Документы кладите в эту папку — ссылки во вкладке появятся сами.
3. Во вкладке: аналоги → цена → сценарии (выберите чек-лист) → аудитории → КП → каналы. Смотрите «Стратегия заполнена».
4. **Меню → Создать план недели** — задачи недели; ассистент начинает 03, SMM — 04.
5. В понедельник — отчёт клиенту.

Ошиблись в ID — исправьте в 01: ID заменится в задачах, обзвоне, контенте, архиве, вкладке и в имени папки. Переименовали объект — переименуется вкладка.

## Пример

**Сервис → Загрузить пример (ЖК Время · Лермонтовская 1)** — объект по реальным материалам (анализ, отчёт № 5, таблица медцентров): заполненная стратегия, задачи 14–18.09 и 21–25.09, 22 компании обзвона, контент. Заказчик, № договора и ссылки на файлы в примере условные (код хранится в публичном репозитории) — замените в таблице. Пример можно удалить: строки с ID «ВРЕМЯ-1» в 01–04 и вкладку.

## Объект уже в работе давно

Внесите стратегию во вкладку, а прошлую работу — одной задачей-итогом в 02 («Итоги работы до ведения системы») и строками 03 по уже обзвоненным компаниям с их датами.
