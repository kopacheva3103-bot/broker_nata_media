# 15 — Личные кабинеты (сайт поверх системы)

Сотрудники работают в кабинете по ссылке (компьютер и телефон), а не в листах таблицы. Таблица остаётся базой данных: всё, что внесено в кабинете, сразу видно в таблице, в отчётах, календаре и сводках.

## Роли (07_СПРАВОЧНИКИ → «Сотрудник / Роль / Email»)
| Роль | Видит | Может |
|---|---|---|
| Директор (Руководитель / владелец таблицы) | всё | всё; раздел «Команда»; кнопка «Таблица» |
| Ассистент | объекты директора (Ответственный пустой или директор) и объекты, где он ассистент | задачи, база обзвона; «Результаты SMM» — только вышедшие публикации по этим объектам (дата, площадка, ссылка, просмотры, охват, заявки), без контент-плана, сценариев и аналитики SMM |
| Агент | объекты, где он «Ответственный» в 01_ОБЪЕКТЫ | задачи, база; «Результаты SMM» по своим объектам (как у ассистента) |
| SMM | все объекты (маркетинг компании) | контент по любому объекту, свои задачи; базу обзвона не видит |

## Разделы
Сегодня (просрочки, задачи на сегодня, звонки и повторные контакты, контент) · Объекты (карточка: задачи, база, контент, стратегия, реклама, отчёты) · Задачи · База (звонок / КП / ответ / следующий шаг в одном окне) · Контент · Команда (директор).

## Как включить (один раз, руководитель)
1. Расширения → Apps Script → «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение».
2. «Запуск от имени» — «Пользователь, у которого есть доступ к веб-приложению»; «У кого есть доступ» — «Все, у кого есть аккаунт Google».
3. «Развернуть» → ссылка «Веб-приложение» = адрес кабинетов. Меню таблицы «➜ Личные кабинеты (сайт)» показывает ссылку.
4. У каждого сотрудника: строка в 07_СПРАВОЧНИКИ (имя, роль, email его Google-аккаунта) и доступ к таблице. При первом входе Google попросит разрешения — «Разрешить».
5. После обновления кода: «Управление развертываниями» → карандаш → «Версия: новая версия» → «Развернуть». Ссылка не меняется.

Права в кабинете проверяются на сервере. Полная изоляция данных (сотрудник физически не может открыть чужое) — на этапе собственной программы с базой данных.

## Кабинет SMM (раздел «Контент»)
- **Контент-план** — календарь: текущая неделя + 2 недели вперёд (кнопки «◀ неделя / неделя ▶», «Сейчас + 2 недели» или свои даты), по дням Пн–Вс.
  - Публикация (тема со всеми площадками) **переносится перетаскиванием** на другой день или кнопками ‹ › (на день), «+7 дн» (на неделю). «+» в дне — новая публикация на этот день. ⧉ — дублировать тему на другие площадки (кросспостинг: Telegram → Instagram, ВКонтакте, YouTube и т.д.).
  - **«Заполнить по нормам»** — ставит заготовки тем (статус «Идея», ✎ + что публиковать) по рубрикам, которых не хватает до нормы на выбранный период; дни — наименее загруженные, без воскресений, прошедшие дни не трогает. Повторное нажатие не дублирует.
  - **Нормы рубрик и воронка** — сколько тем каждой рубрики в плане и сколько нужно по частоте; доли воронки (охват / прогрев / продажа) против цели 30 / 40 / 30. Одна тема на нескольких площадках считается одной темой.
  - **Банк идей** — публикации без даты; перетащите на день.
  - Поля публикации: рубрика, этап воронки (по умолчанию из рубрики), тема, крючок (первые 3 секунды), сценарий / текст, CTA, ТЗ на съёмку, статус (Идея → Сценарий → Снято → Смонтировано → Опубликовано).
  - «Выгрузить план» — Google Документ (+ Word) в «05_СММ», с крючками, CTA и таблицей норм.
- **Опубликовано** — таблица публикаций с цифрами: просмотры, охват, лайки, комментарии, сохранения, репосты, подписки с публикации, заявки.
- **Аналитика** — за период (7 дней / 30 дней / квартал / свои даты): итоги, вовлечённость, подписчики по площадкам (было → стало), рубрики по среднему охвату (что приносит охваты), площадки, форматы, объекты и общий контент, топ-10, выводы. «Выгрузить отчёт» — Google Документ.
- **Соцсети** — раз в неделю по каждой площадке: подписчики, отписки, охват, просмотры, пересылки, переходы в профиль, заявки (лист 11_СОЦСЕТИ). Прирост к прошлой неделе считается сам. Старые цифры не переносились — статистика ведётся с нуля.
- Рубрики — 07_СПРАВОЧНИКИ → «Рубрика (хэштег)»: частота (Каждую неделю / Раз в 2 недели / Раз в месяц / 2 раза в неделю / По поводу — без нормы), что публикуем, где (все соцсети или закрытый Telegram-канал, рубрики «ЗК · …»), этап воронки. Можно дописывать и менять. Цели воронки — «Этап воронки» / «Цель, %».
- Площадки: Instagram, Telegram, Telegram (закрытый канал), Threads, ВКонтакте, Max, YouTube и др.
- По ссылке на публикацию сами подтягиваются просмотры/охват Instagram и Threads (если подключены), Telegram и YouTube; ВКонтакте и Max — вручную.
