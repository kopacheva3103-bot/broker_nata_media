# 15 — Личные кабинеты (сайт поверх системы)

Сотрудники работают в кабинете по ссылке (компьютер и телефон), а не в листах таблицы. Таблица остаётся базой данных: всё, что внесено в кабинете, сразу видно в таблице, в отчётах, календаре и сводках.

## Роли (07_СПРАВОЧНИКИ → «Сотрудник / Роль / Email»)
| Роль | Видит | Может |
|---|---|---|
| Директор (Руководитель / владелец таблицы) | всё | всё; раздел «Команда»; кнопка «Таблица» |
| Ассистент | объекты директора (Ответственный пустой или директор) и объекты, где он ассистент | задачи, база обзвона, контент по этим объектам |
| Агент | объекты, где он «Ответственный» в 01_ОБЪЕКТЫ | задачи, база, контент по своим объектам |
| SMM | все объекты (маркетинг компании) | контент по любому объекту, свои задачи; базу обзвона не видит |

## Разделы
Сегодня (просрочки, задачи на сегодня, звонки и повторные контакты, контент) · Объекты (карточка: задачи, база, контент, стратегия, реклама, отчёты) · Задачи · База (звонок / КП / ответ / следующий шаг в одном окне) · Контент · Команда (директор).

## Как включить (один раз, руководитель)
1. Расширения → Apps Script → «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение».
2. «Запуск от имени» — «Пользователь, у которого есть доступ к веб-приложению»; «У кого есть доступ» — «Все, у кого есть аккаунт Google».
3. «Развернуть» → ссылка «Веб-приложение» = адрес кабинетов. Меню таблицы «➜ Личные кабинеты (сайт)» показывает ссылку.
4. У каждого сотрудника: строка в 07_СПРАВОЧНИКИ (имя, роль, email его Google-аккаунта) и доступ к таблице. При первом входе Google попросит разрешения — «Разрешить».
5. После обновления кода: «Управление развертываниями» → карандаш → «Версия: новая версия» → «Развернуть». Ссылка не меняется.

Права в кабинете проверяются на сервере. Полная изоляция данных (сотрудник физически не может открыть чужое) — на этапе собственной программы с базой данных.
