# J. Инструкция для ассистента

## Главное правило

**Каждое значимое действие по объекту = одна строка в 03_ДЕЙСТВИЯ.** Всё остальное (статистика, план-факт, дэшборд, отчёт) считается само. Не нужно переносить цифры в другие листы.

Не нужно вводить в таблицу то, что есть в CRM: телефоны, переписку, подробные комментарии. Здесь — только действие, результат, цифры, вывод и следующий шаг. Ссылку на карточку в CRM можно вставить в поле «Ссылка на CRM».

## Цвет заголовка столбца подскажет, трогать ли его

| Заголовок | Значит |
|---|---|
| Тёмный | вводите вы |
| Серо-голубой | формула — не трогать (Google предупредит) |
| Светло-серый | заполняет скрипт (ID, ссылки, даты) |

## Куда что вносить

| Ситуация | Куда |
|---|---|
| Позвонили, сделали рассылку, выложили пост, обновили объявление, показ, переговоры, встреча с партнёрами | **03_ДЕЙСТВИЯ** или меню **➜ Добавить действие** |
| Покупатель проявил интерес, был показ, отказ | **03_ДЕЙСТВИЯ** — цифры в счётчиках, причину отказа из списка. Карточку покупателя ведёте только в CRM |
| Задача на неделю | **06_ПЛАН_ФАКТ** |
| Задача переносится | в 06 статус **«Перенесено»** — копия на следующую неделю создастся сама |
| Новый объект | **01_ОБЪЕКТЫ** — новая строка, **ID объекта = номер из CRM** (см. «Первый объект») |
| Цена изменилась | меняете в 01 — история сохранится сама |

## Действие (03) — как заполнить хорошо

Самый быстрый способ — **➜ Добавить действие** (форма). Если вводите прямо в лист:

1. **Дата** (можно не ставить — будет сегодня), **ID объекта** из списка, **Тип**, **Канал**, **Ответственный**.
2. **Факт** — что сделано, *нормальным языком для клиента*: «Презентация объекта пулу брокеров премиум-сегмента», а не «брок. обзвон, 3 недоз.».
3. **Цифры**: контакты, ответы, заинтересованные, презентации, показы… Пример: 50 контактов → 8 ответов → 3 заинтересовались → 2 получили презентацию → 1 показ → 1 переговоры.
4. **Обратная связь** — что сказал рынок («нравится планировка, смущает стоимость обслуживания»). **Причина отказа** — из списка.
5. **Вывод** и **Следующий шаг** с датой.
6. **Комментарий** — внутреннее, клиент не увидит.
7. Галочка **«В отчёт клиенту»** стоит по умолчанию. Снимите её для чисто внутренних действий (чистка базы, внутренние созвоны).
8. **Статус** по умолчанию «Выполнено». Если заносите действие заранее — «Запланировано»; когда сделаете, поменяйте на «Выполнено» и впишите цифры. Запланированное действие с прошедшей датой станет красным.

ID, неделя, автор ставятся автоматически.

## Лиды

Отдельного листа лидов нет — покупатели живут в CRM. **Лиды = столбец «Количество заинтересованных» в 03**: сколько человек после действия проявили интерес. Отказ — выберите «Причину отказа» и опишите реакцию в «Обратной связи». Так система видит, какой канал даёт интерес и почему рынок отказывает, без двойного ввода.

## Недельный цикл

**Понедельник**
- **➜ Создать план недели** (пусто = текущая неделя, с пятницы — следующая). Согласитесь перенести незакрытые задачи.
- В 06 допишите задачи, цели недели и ответственных, покажите руководителю.

**Каждый день**
- Заносите действия в тот же день.
- Утром — **➜ Проверить просрочки**. Закройте или перенесите просроченное, назначьте ответственных.

**Пятница**
- В 06 проставьте статусы задач, для невыполненных — «Причина невыполнения», для всех — «Вывод».
- **07_ОТЧЕТ**: выберите объект и неделю, прочитайте предпросмотр. Если что-то звучит внутренне — поправьте «Факт»/«Вывод» в 03 или снимите галочку «В отчёт клиенту».
- Руководитель пишет комментарий → **➜ Создать отчёт** → проверка документа → при правках **➜ Создать PDF**.
- **➜ Создать план недели** на следующую неделю.

## Порядок в системе

- Ничего не удаляйте из журналов. Ошибочное действие — статус «Отменено» и комментарий.
- Не переставляйте, не переименовывайте и не вставляйте столбцы внутри журналов.
- Не вводите ничего в серо-голубые столбцы — сломается формула всего столбца (станет `#REF!`). Если случилось — удалите введённое значение, формула восстановится.
- Раз в неделю — **➜ Обновить статистику** (проставит пропущенные ID, добавит строки, если журнал заканчивается).
