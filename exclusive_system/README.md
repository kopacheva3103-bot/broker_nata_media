# СИСТЕМА УПРАВЛЕНИЯ ЭКСКЛЮЗИВАМИ

Управленческая система продажи эксклюзивных объектов недвижимости на Google Sheets + Google Docs + Google Apps Script.

```
ОБЪЕКТ → ДЕЙСТВИЕ → РЕЗУЛЬТАТ → СТАТИСТИКА → ВЫВОД → СЛЕДУЮЩИЙ ШАГ
CRM — операционка по клиентам · Таблица — управление продажей объекта · PDF — еженедельный отчёт клиенту
```

Система ставится **одной командой** из меню: код сам создаёт 13 листов, формулы, выпадающие списки, условное форматирование,
защиту формул, папки Google Drive, шаблоны отчёта и стратегии, триггеры. Данные вводятся один раз — всё остальное считается.

## Что в репозитории

| Путь | Что это |
|---|---|
| `apps_script/` | Весь код Apps Script (вставляется в таблицу) — **H** |
| `docs/01_АРХИТЕКТУРА.md` | **A** архитектура, **B** схема связей, **C** листы, источники показателей, что видит клиент, предложения |
| `docs/02_ПОЛЯ.md` | **D–F** все поля: вручную / формула / скрипт (сгенерировано из кода) |
| `docs/03_ФОРМУЛЫ.md` | **G** все формулы (сгенерировано из кода) |
| `docs/04_УСТАНОВКА.md` | **I** установка |
| `docs/05_РУКОВОДИТЕЛЬ.md` | инструкция для руководителя |
| `docs/06_АССИСТЕНТ.md` | **J** инструкция для ассистента |
| `docs/07_ПЕРВЫЙ_ОБЪЕКТ.md` | **K** первый реальный объект |
| `docs/08_ТЕСТИРОВАНИЕ.md` | тестовые данные, ожидаемые значения, что проверено |
| `docs/09_ОШИБКИ.md` | **L** ошибки и исправления |
| `tools/` | проверки для разработчика (Node.js): `check_formulas.js`, `gen_docs.js`, `build_test_workbook.js` |

## Быстрый старт

1. Новая Google Таблица → Расширения → Apps Script → вставить файлы из `apps_script/` (подробно — `docs/04_УСТАНОВКА.md`).
2. Меню **УПРАВЛЕНИЕ ЭКСКЛЮЗИВАМИ → Сервис → ⚙ Установить / обновить систему**.
3. **Сервис → Загрузить тестовые данные** → **Сервис → Запустить самопроверку** (101 проверка).
4. Реальная работа — в чистой таблице: `docs/07_ПЕРВЫЙ_ОБЪЕКТ.md`.

## Для разработчика

```bash
node exclusive_system/tools/check_formulas.js   # генерирует и проверяет все 426 формул
node exclusive_system/tools/gen_docs.js         # пересобирает docs/02 и docs/03 из схемы
```
Структура данных описана один раз в `apps_script/01_Schema.gs`; формулы, списки, защита, onEdit и документация строятся из неё.
