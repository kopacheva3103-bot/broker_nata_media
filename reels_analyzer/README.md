# Анализатор Reels конкурентов

Программа разбирает ролики конкурентов как профессиональный маркетолог и выдаёт:

- **разбор каждого ролика** — хук (визуал, текст, первая фраза, тип), структура по секундам,
  механики удержания, монтаж, триггеры, что даёт сохранения/репосты/подписки, почему залетел;
- **закономерности** по всем роликам — какие хуки, форматы, темп и темы работают;
- **банк из 30 хуков** под вашу нишу;
- **контент-стратегию** на охват и подписки;
- **готовые ТЗ** на ролики (сценарий по секундам, съёмка, монтаж, CTA, подпись, обложка);
- **контент-план** на 2 недели.

## Как это работает

1. Видео скачиваются из папки Google Диска (или берутся из локальной папки `videos/`).
2. Из каждого видео извлекается: длительность, склейки (темп монтажа), кадры
   (0 / 0.5 / 1 / 1.5 / 2 / 3 с — хук, дальше каждая смена сцены и финал), расшифровка речи с таймкодами.
3. Кадры, речь и цифры отправляются в Claude — он делает разбор по каждому ролику.
4. Все разборы сводятся в отчёт с закономерностями и ТЗ.

## Google Диск

Папка **«Анализ Reels конкурентов»**:
- `01_Видео конкурентов (загружать сюда)` — сюда загружайте ролики (mp4/mov);
- `02_Отчёты анализа` и `03_ТЗ на мои Reels` — для готовых результатов;
- таблица `Статистика роликов (заполнить)` — просмотры, лайки, подписчики автора. Необязательно,
  но с ней анализ точнее: программа считает отношение просмотров к подписчикам (виральность).

Чтобы программа скачала видео сама, откройте доступ к папке `01_Видео...`:
«Поделиться → Все, у кого есть ссылка → Читатель».

## Установка (один раз)

Нужен Python 3.10+.

```bash
cd reels_analyzer
pip install -r requirements.txt
cp config.example.env .env      # и вставьте свой ключ ANTHROPIC_API_KEY
```

Ключ API: https://console.anthropic.com → API Keys.

## Запуск

```bash
# видео прямо с Google Диска
python analyze.py --drive "https://drive.google.com/drive/folders/<id папки 01_Видео>"

# или из локальной папки + статистика (скачайте таблицу как CSV → stats.csv)
python analyze.py --videos videos --stats stats.csv
```

Полезные параметры:

| параметр | что делает |
|---|---|
| `--niche "..."` | ваша ниша (по умолчанию — брокер по недвижимости) |
| `--goal "..."` | цель (по умолчанию — охват и подписчики) |
| `--briefs 15` | сколько ТЗ сделать (по умолчанию 10) |
| `--no-speech` | не распознавать речь (быстрее, для роликов под музыку) |
| `--whisper medium` | точнее распознавание речи (медленнее) |
| `--force` | заново разобрать уже разобранные ролики |

Уже разобранные ролики кэшируются в `output/analyses/`, поэтому можно докидывать новые видео
и перезапускать — платить повторно за старые не придётся.

## Результаты (`output/`)

- `отчёт_и_ТЗ.md` — главный документ: выводы, закономерности, банк хуков, стратегия, ТЗ, план;
- `разборы_роликов.md` — подробная карточка каждого ролика;
- `таблица_роликов.csv` — сводная таблица (открыть в Google Таблицах);
- `analyses/*.json` — сырые разборы.

Готовые файлы можно загрузить в папки `02_Отчёты анализа` и `03_ТЗ на мои Reels` на Диске.

## Советы по подборке роликов

- 10–30 роликов — оптимально для поиска закономерностей;
- берите ролики, которые набрали в 3+ раза больше просмотров, чем у автора подписчиков;
- добавьте 3–5 ваших роликов (удачных и неудачных) — в отчёте будет видно, чем они отличаются;
- скачивать ролики из Instagram удобно через сервисы типа «Instagram reels downloader».
