# broker_nata_media

Производство видео для маркетинга Натальи Копачевой: агенты готовят кадры, монтажёр собирает ролик.
Код публичный, поэтому видео, ключей и секретов в репозитории нет.

## Контент-агенты

В папке [`agents/`](agents/README.md) лежат агенты: поиск архивных и стоковых фото, генерация кадров,
оживление через Kling и колоризация. Они работают по брифу серии и передают файлы через Яндекс.Диск.
Ключи хранятся только локально в `agents/.env`, в репозиторий они не попадают.

## Монтаж роликов

В папке [`montage/`](montage/README.md) лежит программа для сборки вертикальных роликов: цветокоррекция,
субтитры, слайды, переходы и музыка. Сценарий монтажа (`project.yaml`) для серии собирает
`./run.sh <серия> montage` из брифа и готовых кадров.
