# Сайт: ремонт под ключ

Одностраничный сайт в `index.html`, фото объектов в `img/` (выбраны из папки «Примеры работ» на Яндекс.Диске).

Перед публикацией замените в `index.html`:
- `CONTACTS` в начале `<script>` — телефон, WhatsApp, Telegram;
- фрагмент сметы в блоке `#smeta` — на реальный фрагмент из вашей сметы.

Чтобы открыть локально, просто откройте `index.html` в браузере. Для хостинга подойдёт любой статический хостинг (GitHub Pages, Tilda-zero-блок, reg.ru и т.п.) — загрузите папку целиком.
